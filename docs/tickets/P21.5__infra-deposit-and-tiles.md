## In scope — deliverables
1. **Zenodo deposit:** `ZenodoHttpTransport` implementing `ZenodoTransport` over `httpx`; `sig-exports deposit --sandbox` creates/updates a deposit with the compartment-aware licence metadata, uploads the export bundle + `sbom.cdx.json` + `CITATION.cff` (new, root), publishes, and writes the concept DOI + version DOI to `docs/build/DEPOSITS.md`; `--dry-run` remains default. `FakeZenodoTransport` tests extended with the real request shapes.
2. **Object store + cache + egress alarm:** `sig-exports push --store s3://…` (boto3 already a dep for evidence Object Lock — reuse) uploading exports with content-hash keys and `Cache-Control`; `ops/` gains the CDN/cache config template (CloudFront **or** R2 — pick one in ADR-067, keep the other as documented alternative) and an **egress budget check** (`sig-ops egress-report` reading the store's usage API when available; alarm threshold in `ops/config.toml`; ADR-015 revisit trigger now has a measurement). Torrent/IPFS offload: produce a `.torrent` for each bulk export (pure-Python bencode; no daemon) as the low-cost mirror path.
3. **Tile generation (LD-F07 / LD-H08):** `sig-exports tiles --in <geojson export> --out <pmtiles>` using `tippecanoe` if present on PATH, else a documented pure-Python fallback for small extents (the OKC point layer is small); output validated by the existing PMTiles reader; ODbL layer metadata preserved (ADR-048). `web/` map page consumes the rendered tiles in `export` mode.
4. **MapLibre island — only if A1 unticked:** `web/src/components/MapIsland.astro` (`client:visible`), MapLibre GL from the OSI-licensed npm package, keyboard-accessible with the zero-JS static map as the no-JS/fallback content; lhci override documented for `/map/` only; a11y e2e for both modes.
5. **Mirrors + Software Heritage (SIG-GOV-022/023/024):** `docs/build/SUCCESSION.md` (what is deposited where, how to rebuild the site from Zenodo + the repo); `sig-ops swh-save` triggering a Software Heritage "save code now" for the repo URL (public API, no token needed for public repos — token optional); mirror manifest (`ops/mirrors.toml`) with at least the Zenodo + object store entries.
6. **Degraded-but-alive mode (SIG-GOV-021, RISK-P0-12, LD-P07):** `sig-ops degraded` builds the fully static site (no API), with every dynamic page showing its last-export as-of banner; a scheduled GitHub Actions workflow (`.github/workflows/keepalive.yml`, monthly) that rebuilds the static site from the last committed export snapshot and fails loudly if it cannot — the "dormant-scheduler keepalive" test the governance doc promises; documented monthly cost = 0 beyond the static host.
7. **ADR-067** (deposit/store/tiles/degraded-mode decisions; reconciles `cloudflare-r2:sig-bulk` vs ADR-015); risk register (`RISK-P21-08` sandbox DOI ≠ production DOI → `DEPOSITS.md` marks sandbox; `RISK-P21-09` egress alarm untested against a real bill → threshold documented, revisit); traceability; `docs/build/INFRA_RUNBOOK.md` (how to run each of 1–6 with the env names).
