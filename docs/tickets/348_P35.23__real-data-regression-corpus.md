## Goal

Build the real-data regression corpus and its two harnesses (L3 CONF-08 / SIG-CONF-008): licence-aware captured slices — one per recorded failure archetype — with oracles computed from the source bytes by code independent of the pipeline; committed slices respect their licences (restricted slices run in a scheduled job whose digests are committed); snapshot changes require an explicit commit. The **M-4 perturbation** and **M-5 hard-negative** harnesses run the corpus in CI for PRs touching connectors/resolution/reconcile/exports/db, and every report header names its estimand (SIG-CONF-012 — never presented as real-world precision/recall).
