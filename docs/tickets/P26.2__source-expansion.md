# P26.2 — Source expansion: promote-class implementation + registry growth (P26)

- **Semantic id:** `SOURCES.2` · **Phase:** 26 · **Kind:** ticket · **Tag:** p26-sources
- **base_branch:** current checkout · **Depends on:** P25.1–P25.6 (class connectors + the disposition triage), P26.1 (scheduled runs give promoted sources a cadence home)
- **Run:** `implement-spec spec=docs/tickets/P26.2__source-expansion.md live_verification=true`
- **Gate status:** engineering under a recorded operator blanket disposition — **GL-GATE-06 (LEDGER GATE DECISIONS, 2026-09-16)**: any source whose rights block resolves to a clear public licence (CC0/CC-BY/CC-BY-SA/ODbL/MIT/public-records/open-API terms) may be flipped to `ingestion_permitted=true` with `rights_reviewed_by="maintainer (delegated)"` + `rights_reviewed_on`. Sources whose terms are UNRESOLVED/UNDETERMINED, ambiguous, or `not_contacted` stay `false` — the blanket covers only resolved-clear licences.
- **Live stage:** real fetches attempted for promoted sources whose existing rights record already permits (most need an HG-03 decision first — the honest outcome may be `refused`/`gate-pending` recorded, not a fabricated fetch).

## Goal
The registry holds 163 sources; 25 are loadable; P25.6 dispositioned every unmapped row
(38 link_only / 43 reference / 8 mirror / **9 promote**). "Maximal expansion" has two
honest legs: (a) make the 9 promoted sources *real* — each already names its class
ticket — and (b) widen the registry with a disciplined discovery sweep so the coverage
map itself grows. Every new row still enters `ingestion_permitted=false` behind a rights
packet — expansion widens the *map*, never shortcuts the *gate*.

## In scope — deliverables
1. **Promote-class implementation.** For each of the 9 `promote` rows —
   `civicclerk`, `courtlistener_recap`, `documentcloud`, `eyes_on_flock`,
   `fbi_cde_agency_registry`, `legistar`, `openstates`, `primegov`, `sam_gov`:
   - implement (or file into its existing class connector) a real fetch/parse path —
     these are civic-meeting/agenda portals (CivicClerk, Legistar, PrimeGov), federal
     records/procurement APIs (CourtListener/RECAP, DocumentCloud, SAM.gov, OpenStates),
     a Flock-watch aggregator, and the FBI CDE agency registry;
   - committed fixtures + unit tests matching the class-connector conventions;
   - `live_targets.toml` rows where a real endpoint exists; a live fetch attempted and
     its outcome recorded honestly (fetch / refusal / robots / paywall / rate-limit);
   - any source whose terms resolve to a GL-GATE-06-covered licence is flipped under
     that disposition (recorded per-row); unresolved/ambiguous terms stay
     `ingestion_permitted=false` with the blocker named — the row's disposition stops
     being aspirational.
2. **Discovery sweep.** A systematic pass adding *new* registry rows for coverage gaps:
   - **more US jurisdictions'** published surveillance disclosures (CCOPS-covered
     cities' public reports, ALPR/RTCC policy PDFs, procurement portals);
   - **more records/procurement surfaces** (additional MuckRock projects, state open
     data portals with surveillance-relevant datasets);
   - **more national registers** in the France-RAA pattern (EU member-state camera
     registries with public data surfaces — NOT declaration portals like
     declarationcamera);
   - each new row: `sources.toml` entry + a rights-packet skeleton +
     `live_dispositions.toml` classification; rows whose packet resolves to a
     GL-GATE-06-covered licence may be flipped under that disposition, all others
     enter `ingestion_permitted=false`;
   - the P25.6 completeness assertion must still pass (`mapped ∪ link ∪ reference ∪
     mirror ∪ promote == registry size`) — now over the widened registry.
3. **Registry hygiene.** `sig-connectors validate` green over the widened registry;
   every new row carries a `live_disposition` or a mapped connector — no orphan rows.

## Out of scope
- `ingestion_permitted` flips for sources NOT covered by GL-GATE-06 (unresolved or
  ambiguous terms need a fresh operator/counsel decision); outreach to source
  operators (skipped by operator — rows stay `not_contacted` honestly); building
  connectors for LINK/REFERENCE/MIRROR rows (they are, by disposition, not live feeds).
- declarationcamera — investigation closed it (declaration portal, not a public
  register; recorded in its rights packet).
