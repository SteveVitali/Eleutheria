# P26.15 — EU tender sweep via TED API (P26)

- **Semantic id:** `SOURCES.14` · **Phase:** 26 · **Kind:** ticket · **Tag:** p26-sources
- **base_branch:** `devin/p26-14-federal-procurement` · **Depends on:** P26.10 (`procurement_notice` claim shape + vocab), P26.14 (the federal sweep + quota-discipline pattern)
- **Run:** `implement-spec spec=docs/tickets/P26.15__eu-tender-sweep.md live_verification=true`
- **Gate status:** engineering — TED's search API (`ted.europa.eu`) is public; EU tender notices are public records under the EU open-data framework. GL-GATE-06 flips if terms resolve.
- **Live stage:** real API sweeps into the hosted spine; bounded windows; rate-limit events recorded honestly.

## Goal
US procurement is live at municipal + federal tiers. The EU layer is the
same signal internationally: every EU contract notice above threshold is
published on TED — surveillance-relevant tenders from Frontex, Europol,
national police forces, and municipal authorities (~30 countries). TED's
search API is public and keyless — a credential-free international
expansion, and the first non-US procurement surface.

## In scope — deliverables
1. **TED source + connector.** A `ted_eu` source row; the TED search API
   swept over surveillance keywords (English keyword set — CCTV,
   surveillance camera, automatic number plate / ANPR, facial recognition,
   drone/UAV detection or procurement, acoustic gunshot, biometric,
   predictive policing + CPV codes where they sharpen precision);
   fixtures + tests; `procurement_notice` claims (notice id, buyer,
   country, value where stated, description, matched keyword) with
   verbatim literals + locators.
2. **Jurisdiction handling.** Non-US rows carry the `jurisdiction_scheme`
   convention from P26.9 (ISO country + member-state subdivision where
   the notice provides it).
3. **Bounded windows.** TED enforces fair-use limits — page-bounded
   sweeps, recorded back-off, honest rate-limit events; never re-probe a
   refused request.
4. **Hosted run.** `sig-ingest-ted-eu` job + monthly scheduler; run rows
   + fetch records; spine delta; idempotent re-run.
5. **Records.** live_runs/ + GCS run rows; rights packet (EU open-data /
   public-record basis); ladder re-measured.

## Out of scope
- Non-English keyword sweeps per member state (a precision trade-off —
  the English + CPV slice first; deeper localisation is a later ticket);
  national portals below the TED threshold; award-vs-tender lineage.
