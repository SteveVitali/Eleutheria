## Goal
Implement the three OKC document-connector modules the fixtures already encode but no live
connector exercises — `okc_procurement`, `okcpd_policy`, `ok_statute` — so that, once their
sources are flipped green (RIGHTS.1), the composed pipeline can fetch → capture → parse →
emit the same claims the fixtures assert, byte-identically under shadow replay.
