# P27.3 — Export data-shaping: geometry, jurisdiction, dedup, coverage (P27)

- **Semantic id:** `LAUNCH.3` · **Phase:** 27 · **Kind:** ticket · **Tag:** p27-launch
- **base_branch:** `devin/p27-2-maximize-publishable-scope` · **Depends on:** P27.1 (contracts + resolution-posture decision), P27.2 (publishable inputs)
- **Run:** `implement-spec spec=docs/tickets/P27.3__export-data-shaping.md live_verification=true`
- **Gate status:** engineering — reads the spine, computes derived shapes. If P27.1's posture is *materialize*, adds sqitch changes (append-only) + a resolution run; if *compute-on-read*, no spine writes.

## Goal
Turn 1.06M raw claims + 75k bare geolocated entities into the shaped datasets the public surfaces
need: point geometry, per-jurisdiction grouping, cross-source de-duplication (or honest
observation-level framing), and coverage aggregates with named denominators. This is the missing
layer between the append-only claim spine and any meaningful national view — done **once** at export
time (the right place for a static site).

## Load (cite; do not copy)
- `docs/2_canonical_design_spec.md` §16 (spine), §29 (reconciliation / resolution envelope), §32 (coverage; "never publishes a total", named denominators; SIG-METRIC-008), §19.4 + §43.3 (coordinate reduction to sensitivity tier), §21.6 (lineage).
- Code: `resolution/`, `reconcile/`, `inference/`, `api/src/api/store_pg.py` (`dossier`/`coverage_for`/`entity` + the enumeration methods to add), `db` `resolution`/`jurisdiction`/`coverage_record` tables (currently empty), the P21.2 compute-on-read family (ADR-037/038/039/054).
- `docs/build/reports/P27.1` per-page contracts + resolution posture.

## In scope — deliverables
1. **Geometry assembly.** Parse `camera_latitude`/`camera_longitude` (text) into points per entity;
   emit through the **normalization path** (never a hand-edit of `value_geom`) so lineage holds.
   Reduce precision to each site's sensitivity tier (§19.4) even though all rows are tier-0 today.
2. **Jurisdiction grouping.** Derive per-jurisdiction membership from `camera_jurisdiction` (including
   the honest `unresolved` bucket — 16,859 rows); expose it as a queryable grouping.
3. **Cross-source resolution/dedup.** Run `resolution`/`reconcile` over the camera entities to merge
   duplicates across `dot_511`/`osm`/`atlas`/`flock_portal` per P27.1's posture — either populate the
   `resolution` envelopes (append-only sqitch + `python -m reconcile resolve --dsn`) or compute
   observation-level dedup at export time with an explicit "N observations, M resolved sites" honesty
   line. Contradictions stay visible (§3.1), never silently merged.
4. **Coverage aggregation.** Compute the §32 coverage shapes — counted quantities with named
   denominators, per-jurisdiction site counts, freshness inputs — **no totals, no population estimate**.
5. **Enumeration read methods.** Add the `PgReadStore` reads P27.4 needs: list publishable scopes /
   jurisdictions, list geolocated sites (shaped), list sources + freshness, list sharing edges.
6. **Records:** `docs/build/runs/P27.3.md`, PR body; sqitch change(s) iff materializing (deploy/revert/
   verify); tests on a seeded spine + a live shaping run over hosted.

## Out of scope
- Emitting the export bundle files / web JSON (P27.4); any web change; any `UPDATE`/`DELETE`; inventing
  facts the evidence doesn't support (a missing coordinate is a gap, not a guess).

## Acceptance criteria
- [ ] geolocated claims resolve to points via the normalization path with lineage; a seeded fixture yields the expected GeoJSON-ready shape *(deterministic)*
- [ ] per-jurisdiction grouping (incl. `unresolved`) and coverage aggregates compute with named denominators and no total *(deterministic)*
- [ ] cross-source dedup/resolution runs per the chosen posture; duplicate cameras across sources collapse (or are honestly labelled observation-level); contradictions preserved *(deterministic + live-gated)*
- [ ] new `PgReadStore` enumeration methods are typed + tested; a live run over hosted produces the shaped datasets P27.4 consumes *(live-gated)*
- [ ] `make check` + `make test-db` + build-memory green; append-only holds *(deterministic)*
