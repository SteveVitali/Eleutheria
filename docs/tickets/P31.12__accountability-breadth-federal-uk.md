## In scope — deliverables
1. **Wiring.** For each source: a `CONNECTOR_FOR_SOURCE` entry, an `accountability_vocab.toml` `[sources]` entry, and
   reviewed `live_targets.toml` rows. A committed fixture capture, with a shadow-replay diff = 0 over it. Entity-ref
   claims for the oversight subject (the audited agency or program) where P31.5's identity rule resolves it; text-only
   otherwise.
2. **Hosted land, per source.** Run it **only as a Cloud Run job**: a `sig-ingest-<id>` job running
   `sig-ops scheduled-ingest --source <id> --sink pg` (it builds the DSN from the `SIG_PG_*` parts inside the
   container, with the password from Secret Manager), on a SHA-tagged image deployed **by pinned digest** (never
   `:latest`), with the restricted-bucket capture store mounted (ADR-111 §5) so captures persist and a restart
   resumes. Create **only the new jobs** — do not re-apply `scheduled-ops.sh` over the existing 76 jobs (ADR-111: it
   resets hand-tuned settings); roll new code onto existing jobs with `sig-ops roll-jobs`. Do **not** copy the
   D-R7.3-BREADTH laptop recipe verbatim: it puts the password and the literal project id on a command line. Record
   the `ops/runs` row, the `ingest_run_completion` (ADR-109) and the landed claims, then re-run for +0.
3. **Rights apply.** `sig-db rights-decisions --decisions docs/build/reports/rights/p293_dispositions.json --apply`
   (append-only `rights_decision` rows). Confirm the evidenced licence resolves onto the landed claims.
4. **Deepen.** `materialize.sh --apply run resolution` / `camera-sites` (if relevant) / `accountability`. Record per
   source how many claims landed, were deduped into resolved entities, and linked. Re-run +0.
5. **Cadence.** An `ops/cadence.toml` `[[sources]]` row (job + scheduler) for each yielding source, in the same
   change as its `live_targets` rows (`sig-ops cadence --check` green).
6. A per-source report under `docs/build/reports/p31.12-hosted/`. An honest outcome for any source that yields nothing
   (`link_rotted` / `access_restricted` / `unreachable`), never fabricated.
