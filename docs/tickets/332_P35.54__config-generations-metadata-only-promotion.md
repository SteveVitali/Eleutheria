## Goal

Make promotion a metadata act: the **envsubst-templated nginx** (§4.2 — `SIG_LATEST_PUB`, `SIG_CONF_GEN`, `SIG_STAGING` rendered per revision), the **`conf/<gen>/` configuration generations** (immutable `promoted.map`, `latest.json`, `withdrawn.conf`, `selectors.conf`, `labels.conf`, `releases/` — every instance of a revision agrees), and **`sig-ops release promote`** writing `conf/<gen+1>` — `latest.json` flip, `promoted.map += pub`, `withdrawn.conf`/`selectors.conf`/`labels.conf` carried from the current registry, `releases/` index regenerated by the release tool alone (C4 NEW-10) — then rolling `sig-api` then `sig-web` by **digest** (`min-instances=1` during the flip). Promotion copies **no release bytes**; a new generation flips latest atomically (the catalog AC); an unpromoted namespace 404s.
