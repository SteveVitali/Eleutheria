- **Sequence:** 3 of 46

## Goal
Adopt and publish SIG's **prose governance** policies — takedown/corrections/suppression, the
governance structure and Code of Conduct, the public anti-misuse statement, and contributor
safety — with each executable sub-rule (suppression primitive, corrections-preserve-history) tested.

## Load
- `docs/2_canonical_design_spec.md` §45 (corrections, disputes, takedown), §46 (governance, sustainability, continuity), §34.3 (contributor safety).
- Part 0, Part I §3, Appendix E glossary; cross-ref §16.6 (corrections-as-new-assertions, from P02.1).

## In scope — deliverables
1. **Takedown, corrections & suppression** (§45): intake channels, response SLAs, **suppression as a distinct primitive** (not a delete), **corrections preserve history** (a correction is a new assertion with `supersedes`), the transparency-report shape — SIG-GOV-001…011.
2. **Governance & Code of Conduct** (§46.2): decision-making model, editorial board, capture-resistance, continuity/succession posture — SIG-GOV-014…016, SIG-GOV-021.
3. **The public anti-misuse statement** (§46.3) — stated honestly, addressing the dual-use tension rather than denying it — **SIG-GOV-019**.
4. **Contributor safety policy** (§34.3): OPSEC guidance, no-trespass/no-interference stance, pseudonymity support, PII-minimisation window — SIG-CONTRIB-005…008.

## Out of scope (do NOT do here)
- Executable pipeline rules — licence gate, coordinate matrix, officer test, crawler conduct, threat model — **P00.2** owns them.
- The contributor *system* (tiers, onboarding, revert mechanics, anti-poisoning code) — **P16.1** (§34.1/34.2/34.4); this ticket ships the safety *policy* only.
- The source registry — **P00.4**.

- [ ] **Suppression is a distinct primitive** from deletion, and **corrections preserve prior belief** — proven by a test that an `as_of_belief` before a correction still returns the old value (mirrors §16.6). *(deterministic)*
- [ ] The **anti-misuse statement (SIG-GOV-019)** is published verbatim as a first-class page. *(deterministic — presence check)*
- [ ] Contributor safety policy documents pseudonymity and the PII-minimisation window (SIG-CONTRIB-005…008). *(agentic)*
- [ ] **Phase-gate (§51.3):** CI green incl. data-quality checks; new requirements have automated tests (SIG-ENG-004); ADRs written for any deviation; traceability matrix updated; risk-register entries for this phase updated.
