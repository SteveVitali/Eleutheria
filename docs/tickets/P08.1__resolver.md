## Goal
The §28 resolver — the intellectual core: a `RESOLVE()` that runs the fixed phase pipeline over a
subject/predicate/as-of pair, using a versioned **ruleset-as-data**, the four axes (R·D·I·C), a
deterministic total order with no random tie-break, the ambiguity test, currency handling,
independence/dependence discounting, template-generated rationales, and a human override that never
hides the algorithmic result.

## In scope — deliverables
1. **`RESOLVE(subject, predicate, as_of_world, as_of_belief, ruleset)`** executing Phases 0–7 (gather → admissibility → canonicalize → weight → independence → strategy → ambiguity → emit) in order — SIG-RECON-006.
2. **Ruleset as data** — versioned, diffable, testable, separately attributable from the resolver implementation; a predicate with no strategy is not resolvable (silence → `UNRESOLVED`) — SIG-RECON-005, SIG-RECON-012, SIG-RECON-013.
3. **The four axes**: R per-source from the registry; D from the published (genre × predicate) matrix, with `D6` an admissibility filter (excluded, not down-weighted); I mechanical; C derived at query time from volatility/half-life — SIG-EPIS-014, SIG-EPIS-017/018, SIG-EPIS-019/020, SIG-RECON-008.
4. **Deterministic total order**: the universal, fully-specified tie-break of **SIG-RECON-007** (a total order over composed weight, method breadth, observation time, source-registry rank, and claim id — see §28 for the exact operator direction of each key); **no random tie-break anywhere**.
5. **Ambiguity test** `U0–U8` evaluated in order, including **`U5`** (stale winner on a changing predicate → `UNRESOLVED` with `last_known` + date, even with no dissent) — SIG-RECON-014/015/016/017.
6. **Independence/dependence discounting**: corroboration counted per independence class and per collection method, never per claim (declared, not inferred) — SIG-EPIS-026/027/028, SIG-RECON-018.
7. **Rationale generation** from versioned templates, passing the committed template test (no placeholder; names a source; attributes every value; never a support term and an agreement term in one sentence) — SIG-RECON-022/023.
8. **Human override**: a curator MAY pin a resolution, recording `decided_by` + mandatory `override_rationale`, displayed as an editorial act, without deleting or hiding the algorithmic result — SIG-RECON-024/025.

## Acceptance criteria (from the Phase 8 ACs, sub-set to this ticket)
- [ ] Resolution is deterministic; no random tie-break; the total order is proven by test over identical inputs. *(deterministic)*
- [ ] A Tier-A contract does **not** win `active_device_count` against a `D1` portal snapshot (contract is `D5`/`W1` for that predicate). *(deterministic)*
- [ ] `D6` claims are **excluded**, not down-weighted (a portal snapshot contributes nothing to `contract_signed_date`). *(deterministic)*
- [ ] **`U5` fires**: a stale unchallenged value on a MODERATE/FAST/VOLATILE predicate returns `UNRESOLVED` with `last_known` and a date, even with no dissent. *(deterministic)*
- [ ] Three sources copying one upstream count as **one** independence class. *(deterministic)*
- [ ] Rationales are quotable and never mix a support term and an agreement term in one sentence (template test). *(deterministic)*
- [ ] A human override records author and rationale, and does **not** hide the algorithmic result — both are shown. *(deterministic)*
- [ ] **Phase-gate (§51.3):** CI green incl. data-quality checks; new requirements have automated tests (SIG-ENG-004); ADRs written for any deviation; traceability matrix updated; risk-register entries for this phase updated.

## Notes
