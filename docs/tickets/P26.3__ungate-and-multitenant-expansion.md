# P26.3 — Ungate blocked sources + multi-tenant vendor expansion (P26)

- **Semantic id:** `SOURCES.3` · **Phase:** 26 · **Kind:** ticket · **Tag:** p26-sources
- **base_branch:** `devin/p26-2-source-expansion` · **Depends on:** P26.1 (cadence), P26.2 (promote connectors)
- **Run:** `implement-spec spec=docs/tickets/P26.3__ungate-and-multitenant-expansion.md live_verification=true`
- **Gate status:** engineering under GL-GATE-06 (blanket disposition for resolved-clear licences) + a new ADR for the robots-4xx interpretation. Hard robots disallows (`Disallow: /`) are NEVER bypassed.
- **Live stage:** real fetches per source with recorded outcomes.

## Goal
The measured ladder today: 142 registered → 43 permitted → 28 with live targets → ~18
that have actually produced claims. Close the 43→18 gap: ungate everything ungatable by
legitimate means, and multiply through the multi-tenant vendor platforms where one
connector serves hundreds of municipal hosts.

## In scope — deliverables

1. **Rights-resolution leg (documentcloud, courtlistener_recap).** Complete the rights
   packets against the real published terms (DocumentCloud public API terms;
   CourtListener/Free Law Project open API — RECAP is public court records). Where the
   terms resolve to GL-GATE-06-covered licences, flip with `maintainer (delegated)` +
   date; where they don't, the blocker stays named — no invented resolution.

2. **Robots-4xx ADR (SIG-INGEST-012 amendment).** SIG currently refuses on ANY
   unretrievable robots.txt. RFC 9309 §2.3.1.4 says a **4xx** response means no
   policy exists (unrestricted); only *connection failure* is ambiguous. Write an ADR
   adopting the RFC-correct split: `4xx robots.txt → permitted`, connection
   failure/timeout → still refused. Implement in `connectors/net.py` +
   `policy.crawler`; update SIG-INGEST-012's recorded semantics. This legitimately
   ungates `civicclerk` (its robots.txt 404s) — and only that class of refusal.

3. **Multi-tenant vendor enumeration.** The promote-class vendors host hundreds of
   municipalities. Enumerate real tenant hosts (legistar `*.legistar.com`, civicclerk
   `*.civicclerk.com`/custom domains, primegov `*.primegov.com`, granicus where it
   fits) — a curated target list in `live_targets.toml` keyed per-city, starting with
   the OKC-mapped jurisdictions + the surveillance-heavy metros already in the
   registry's jurisdiction register. Each host's own robots.txt decides; record every
   per-host outcome (claims / refused / link_rotted / unretrievable).

4. **primegov pivot.** `lacity.primegov.com` is `Disallow: /` — never fetched. Route
   the same LA records through `lacity.legistar.com` (the working connector) as the
   recorded substitute, and keep the primegov row honest (`robots_refusal` stands for
   that host).

5. **Credential-blocked rows stay honest.** `sam_gov`/`openstates` need free API keys —
   account actions (operator). Record `D-SOURCES.2-1` remains the blocker; do NOT stub
   around it.

6. **Records.** Per-source outcome rows in the run ledger + `live_runs/` reports; the
   permitted→configured→ingested ladder re-measured and recorded.

## Out of scope
- Bypassing a real `Disallow` — hard robots walls are honored, full stop.
- Registering API keys (operator accounts); flipping sources whose terms don't resolve
  under GL-GATE-06.
- declarationcamera (closed — declaration portal, not a public register).
