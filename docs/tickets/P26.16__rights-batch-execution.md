## In scope — deliverables
1. **Mass flip.** Every gated row in
   `docs/build/reports/catalog_sweep_2026-09-18_reviewed.json` gets: source
   row (if not already registered) + `ingestion_permitted=true` +
   `rights_reviewed_by="maintainer (delegated)"` + review date + the
   GL-GATE-07 licence basis (US vs non-US per row jurisdiction). A scripted
   generator for the rights packets (one packet per dataset or a batch
   packet + per-row annex — the packet convention scales).

   Batched `sig-ingest-camreg-batch-*` jobs (grouped to keep job counts
   manageable — e.g. ~10 jobs × ~26 datasets); run rows + fetch records;
   per-dataset outcomes recorded (produced / empty / error / refused).
3. **DocumentCloud.** Complete the rights packet against DocumentCloud's
   public-document API terms; flip under GL-GATE-06/07 if they resolve;
   run if a connector path exists, else record the connector as owed work.
4. **Hosted runs + spine delta.** All batches executed; idempotent re-run
   on a sample; ladder re-measured.
5. **Records.** `D-SOURCES.12-1` closed or narrowed to its true remainder
   (the 68 probe-error rows are out of scope here — they are infra, not
