## In scope — deliverables

1. **One-off job pattern.** A committed `ops/gcp/` script (dry-run default) and a `sig-ops` helper that define and execute a one-off Cloud Run job: image pinned by digest (ADR-111), a least-privilege SA from P34.42b, a **read-only** gcsfuse mount of `gs://…-sig-restricted/evidence/captures/`, the Cloud SQL connector, only the secrets the run needs, `--max-retries 0`, a task timeout, arguments per execution, and a name-checked cleanup. Used by P34.45 (ER re-run), P34.49 (at-rest scan) and P35.61 (bounded apply). The alternative G2 names — running from the operator's workstation through the proxy — is not used.
2. **`sig_audit` login (L1; SIG-CONF-013).** A LOGIN role, member of `sig_read_public` (the §37 surface, RLS tier 0), `default_transaction_read_only = on`, a `statement_timeout` (L2 used 60 s), a connection limit; credential via Cloud SQL IAM database authentication for `sig-quality-probe-rt`, or a password held only in Secret Manager (HG-09) — chosen in the ticket and recorded in an engineering ADR. Each use writes a `probe-run/1` record (the writer is P34.44a's harness; a smoke run here writes one).
3. **The two tables `sig_read_public` lacks** (`ingest_run_capture`, `entity_identity_key`; L2 §0, NEW-16): SELECT grants to `sig_audit` written as a **new sqitch change appended after L52** (deploy/revert/verify; L44–52 untouched, C-10). It is deployed to hosted only inside P34.46's slot (the hosted plan cannot advance past L43 before it; P34.46's L1 re-rehearses the new tip). Until then the checks that need them report `not_evaluable`.
4. **`sig_recovery` login (L2, `live:P34.46`).** A LOGIN role granted `sig_recovery` (created by L52), for P35.61; credential handled as above.
5. **Verification.** `sig_audit` cannot write (INSERT/UPDATE/DELETE/CREATE refused), its timeout is in force, and it reads `sig_read_public`'s surface; the job's capture mount is mounted read-only (mount options read back) and its SA lacks object create/delete there (read-only IAM analysis) — no destructive write is attempted.
