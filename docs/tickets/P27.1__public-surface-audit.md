## Goal
The public web renders the OKC fixture demo while the spine holds ~1.06M claims. Before we build the
export/web, measure exactly what a **national** public surface can honestly show — publishable
fraction, geolocated inventory, and the modeling gap — and **freeze the per-page data contracts** the
rest of P27 emits (P27.4) and consumes (P27.5). No product code beyond a read-only audit verb.

## In scope — deliverables
1. **A repeatable read-only audit verb** (e.g. `sig-exports audit --dsn …` or a `reconcile`/`api`
   query command) that emits, deterministically over any spine: total claims/entities/sources;
   licence mix (claims by `rights_record.spdx_expression`); **UNDETERMINED by `ingest_run.connector_name`**;
   geolocated entity count (distinct subjects with `camera_latitude`/`camera_longitude`); jurisdiction
   spread (`camera_jurisdiction`); and the modeling-table population (`resolution`, `jurisdiction`,
   `coverage_record`, `relationship`, `physical_asset`, `value_geom`). Unit-tested against a seeded spine.
2. **`docs/build/reports/PUBLIC_SURFACE_AUDIT.md`** — the live snapshot with the exact queries + results
   + caveats (observation-level, pre-resolution; rights→source fan-out).
3. **Frozen per-page data contracts** (a committed JSON-schema or typed-shape doc) for every public
   surface: dossier index, per-jurisdiction dossier, map layer, network, data-freshness, coverage,
   watch, evidence, corrections, research-queue — the interface P27.4 emits and P27.5 renders.
4. **Launch-scope memo** (a section of the report): what the national surface contains now vs after the
   P27.2 rights work; the dedup/resolution posture decision (observation-level vs resolved — recommend
   which, with the trade-off); the ordered publishable-scope list.
5. **Records:** `docs/build/runs/P27.1.md` + PR body. **Do NOT** edit `00_MANIFEST.md`/`LEDGER`/
   `BUILD_INDEX`/`DEFERRALS` in this PR (coordinated pass after P26 lands) — note the intended rows.
