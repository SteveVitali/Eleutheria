## Goal
Merge observation-level camera records that describe the **same physical device** across sources into
resolved entities, with visible provenance and a **measured** precision floor, so the public surface can
honestly report N resolved sites from M observations (N ≤ M), and never merge distinct devices.

## In scope — deliverables
1. **Define the unit and the metric first (and record it).** "Resolved site" = a cluster of observation-level camera records judged to be the same physical device. M = observation-level camera records on the hosted spine; N = post-ER clusters; N ≤ M; dedup ratio = 1 − N/M. Write the definition into the methodology page copy and the eval report.
2. **Geospatial blocking** (new `blocking_rules.toml` rule(s) + code): candidate pairs from a coordinate grid/geohash cell plus its neighbours, sized against the existing block-size ceiling. Blocking only proposes candidates; it never decides.
3. **Matching features + tiers:** distance in metres, shared canonical external reference (deterministic tier when two sources carry the same upstream id, e.g. an OSM node id republished by a mirror), operator/type compatibility, source independence. **Hard constraints that must be test-pinned:** (a) never merge two records from the **same source** (a single source listing two cameras at one spot = two devices); (b) never merge across conflicting device types/operators beyond the recorded rules; (c) a mirror of the same upstream dataset is not independent corroboration.
4. **Eval before auto-write (ADR-099 loop):** extend the gold set with a stratified sample of camera-site pairs (dense urban intersections, highway corridors, rural singletons, cross-source mirrors), agent/maintainer-labelled seed + LLM adjudicator, κ ≥ 0.7 to trust LLM labels, **frozen holdout verified by the agent/maintainer**; auto-write only for tiers whose measured holdout precision ≥ **0.98**; everything below → review queue. Cluster-shape alerts must catch chaining (e.g. mega-clusters strung along a road).
5. **Hosted run in GCP** via `sig-materialize` (tagged image, never `:latest`): run ER over the hosted spine, materialize resolution decisions append-only, measure M, N, dedup ratio, per-tier precision, demotions, alerts; re-run `+0`. Measure throughput early and report an honest ETA before a long run.
6. **ADR (next free number, `## Revisit trigger`, BL-057, Appendix F + `BUILD.sh`)** for the geospatial rule, thresholds, same-source exclusion and the metric definition. Update `P28.1_resolution_eval.md` (scale section from committed measurements) and close D-P30.2-3 with evidence. D-R6.1-EVAL's first-principles half stays OPEN (provisional disclosure preserved).
