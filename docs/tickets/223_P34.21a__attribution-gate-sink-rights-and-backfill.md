## In scope — deliverables

1. **Sink keyed per source.** `PgClaimSink` resolves rights on (source, SPDX, attribution, terms), not SPDX alone, inserting a new `rights_record` per distinct key (ADR-095 pattern; idempotent across replays). *(SIG-LIC-004a, SIG-LIC-011)*
2. **Engineering ADR (next free number; this row owns it)** for the backfill semantics: ADR-095 and the readers (`store_pg.rights_for`: "Decisions only ever have UNDETERMINED priors, so an already-resolved link is never re-licensed") allow a decision only to lift an UNDETERMINED record. Correcting a wrong attribution on an already-resolved record needs a narrowly scoped extension — an *attribution correction* decision whose new record keeps the same `spdx_expression` and redistributability and changes only attribution / terms — so nothing is ever relicensed. The ADR states that rule, adds a test that a decision changing the licence of a resolved record is refused, and appends `Qualified by ADR-<n> (<date -u>)` to ADR-095 in the same PR (S6R-24). Re-confirm the reader rule at build time. *(SIG-STORE-011)*
3. **Backfill tool** (committed, dry-run by default, list input, `--apply`): computes for every source the correct per-source record from the registry (`sources.toml` attribution, terms URL, SPDX) and writes new `rights_record` + `rights_decision` rows with `basis` naming E2-12 and this ADR and `reviewer` a role, never a name; INSERT-only, idempotent (a second run writes 0 rows). The DeFlock misattribution (EFF Atlas rows credited to "DeFlock community map") and the 3,272 wrongly credited CC-BY rows are corrected through it. *(SIG-CONTRIB-020, SIG-STORE-011)*
4. **Readers use the effective per-source record:** exports (every compartment, per-row attribution), the API (`rights_for`; obligations name the right upstream with its terms URL) and the per-compartment map credit (replacing the blanket `_SIG_ATTRIBUTION` "© The SIG project" credit on third-party compartments with the drawn sources; OSM keeps its ODbL credit). *(SIG-EXPORT-006, SIG-API-004, SIG-CONTRIB-020)*
5. **Licence ids and URLs:** valid SPDX ids (e.g. `OGL-UK-3.0`) and LicenseRef URLs in `datapackage.json`; `LICENCES.json` wording no longer promises per-row attribution it lacks; the publication-basis label (E2 H-6, artifact half) in `manifest.json`, `LICENCES.json` and `datapackage.json`, worded as **the operator's own determination (no counsel)** (OM-08, ADR-167, ADR-182) — the sentence goes to the copy batch for republish #2 (B-2). *(SIG-LIC-011)*
6. **Per-file ATTRIBUTION writer:** every export file carries an ATTRIBUTION record; for the ≈ 8,088 express-terms rows kept under A-8 (**"Keep all, accept risk"**, round 4, 2026-10-01T04:07:45Z; ADR-183) it states the captured terms and the operator-accepted basis; refreshes of the same sources are covered (SB-2 **"Yes, same sources (Recommended)"**, round 27, 2026-10-01T13:46:58Z). *(SIG-LIC-011, SIG-EXPORT-006)*
7. **Publish-time attribution gate:** the export build and the P34.10 publish command both fail when any row with `rights_attribution_required = 1` has an empty attribution; a test seeds such a row and the gate refuses it. *(SIG-LIC-011, SIG-OPS-004)*
8. **L1 (hosted, pre-authorised):** the backfill `--apply` on `sig-pg` in the window, then the read-back.
