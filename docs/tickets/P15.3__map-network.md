## In scope — deliverables
1. **Infrastructure map** with the §39.3 layers (physical devices; deployments; RTCCs/integration hubs; sharing edges; private-public networks; service areas; lifecycle status); derived layers (FOV, coverage) separately toggled and visually distinct — SIG-UI-016 (SIG-GEO-006).
2. **Coverage underlay bound to the point layer with a single control** — a user cannot see points without seeing where SIG has not looked — SIG-UI-017.
3. **Low-coverage never reads as low-density**: desaturation / value-suppressing encoding makes "we don't know" visually distinct from "little here" — SIG-UI-018.
4. **National-zoom density binning**; individual points appear only where the zoom supports honest rendering of their precision (H3 binning per §19.5) — SIG-UI-019, SIG-GEO-011.
5. **No-coordinate assets shown as jurisdiction-level indicators**, never silently dropped — SIG-UI-020.
6. **Sharing edges as an ego-network** (with matrix and arc alternatives), never a national hairball — SIG-UI-021.
7. **Self-hosted vector tiles**: MapLibre renderer over **static PMTiles v3** from tippecanoe; third-party tile CDN not a hard dependency; correct OSM basemap attribution in every context incl. print — SIG-UI-038, SIG-GEO-012, SIG-GEO-013.
8. **Network explorer**: default **ego network with expansion** — SIG-UI-022.
9. **Inline ER-quality disclosure on every centrality/hub statistic** (not a footnote) — SIG-UI-023 (P6, SIG-IDENT-030).
10. **Three access edge types visually distinct + independently filterable**, never merged by default — SIG-UI-024 (§12.2).
11. **Access-path closure** showing the full hop list with per-hop evidence, labelling paths beyond the published threshold **speculative** — SIG-UI-025 (SIG-RECON-050).
