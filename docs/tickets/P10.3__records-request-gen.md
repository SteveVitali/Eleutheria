# P10.3 — Records-request generation

- **Sequence:** 26 of 46
- **Phase:** 10 — Research-task generation
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P10.1 (the task engine, disposition vocabulary, geographic queues, and the SIG local-group registry this generator routes into), P09.1 (the `CoverageRecord` written by `resolved_no_evidence_exists`)
- **Run:** `implement-spec spec=docs/tickets/P10.3__records-request-gen.md`

## Goal
Emit ready-to-file public-records requests that carry the **correct statutory citation for the
jurisdiction**, respect operationally-binding residency restrictions, and route residency-blocked
requests to the local-group queue — and close the loop so that a `resolved_no_evidence_exists`
disposition **writes a `CoverageRecord`**, turning negative results into data.

- Always-in-scope context: Part 0, Part I §3 (invariants), Appendix E glossary.

## In scope — deliverables
1. **Request generation** — given a research gap, emit a ready-to-file request with the correct target agency + records contact, the **correct statutory citation for that jurisdiction**, proven request language for the record type, and the specific records sought — SIG-TASK-015.
2. **The per-jurisdiction records-law reference table** covering all **51 US jurisdictions** — statute name/citation, initial response deadline, fee rules, appeal path, and whether a requester-residency requirement applies — SIG-TASK-016.
3. **Residency handling (operationally binding)** — refuse to emit a request naming a non-resident filer in a residency-restricted jurisdiction; **route the task to that jurisdiction's geographic queue** (§33.5) instead; **record the constraint as a coverage fact** so thin evidence there reads as a legal barrier, not an absence; default to the restrictive behaviour where residency status is unknown — SIG-TASK-016a/016b.
4. **`resolved_no_evidence_exists` → `CoverageRecord`** — when a records request comes back with no responsive record, write a `CoverageRecord` (`absence_kind = searched_not_found` + sources searched), exercising SIG-TASK-009 through the records path.
5. **Versioned templates with measured success rates** (denial-producing language flagged for revision; which language works is itself a finding) — SIG-TASK-017.
6. **Consent gate** — SIG does not file on a contributor's behalf without explicit consent and makes clear a filed request is a public act attributable to the filer — SIG-TASK-018.

## Out of scope (scope-creep guard — do NOT do these here)

## Notes
This ticket **owns** the 51-jurisdiction records-law reference table and the residency-routing
contract. Residency is not informational: in the six residency-restricted states (Alabama, Arkansas,
Delaware, Kentucky, Tennessee, Virginia) SIG's records-acquisition capability is exactly its local-
contributor coverage, which makes the P10.1 local-group registry load-bearing here. Unknown residency
defaults to the restrictive behaviour (SIG-TASK-016b) — never assume openness.
