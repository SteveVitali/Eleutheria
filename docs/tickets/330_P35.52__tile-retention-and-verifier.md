## Goal

Stop the map silently dropping published sites (F-414's root cause: tippecanoe ran with default dropping — base zoom = max zoom 14, drop rate 2.5 — so only **0.03 %** of the 227,335 published sites existed at z3, **5.7 %** at z10, **25.6 %** at z12, and nothing replaced the dropped points). Rebuild the overlay to **`sig.map-tiles/2`**: still **one PMTiles archive per licence compartment** (SIG-GEO-012), now with **two layers** — `cells` (H3 count cells for z0–9; res 3 at z0–4, res 4 at z5–6, res 5 at z7–8, res 6 at z9; each cell carries its compartment's published-located count + facet counts — a cross-compartment count archive is a licence-mixed derived database and is never published, K1 §3.2/ADR-106 §4) and `sites` (**every** point retained from its tier's zoom: tier 0 from z10, tier 1 from z11, tier 2 from z12 *as its H3 polygon*, tier 3 **never** drawn). The exporter writes each feature's zoom range as a `"tippecanoe": {"minzoom","maxzoom"}` member; tippecanoe runs with **`-r1`**; `--drop-densest-as-needed`, `--drop-fraction-as-needed` and `--coalesce*` are **forbidden**; an over-size tile **fails loudly**, never silently thins; the pure-Python renderer honours the same ranges, stops coalescing distinct entities that share a cell (`tiles.py:56`), and dedupes only byte-identical features. `web/tiles/index.json` carries `{compartment, path, sha256, licence, attribution (PKG-08), bounds, minzoom, maxzoom, counts{points, cells_by_band}, renderer, renderer_version, contract: "sig.map-tiles/2"}` per archive; file names carry the content hash (`<compartment>-sites.<sha8>.pmtiles`) so nginx can send `immutable` (fixes D12); under G3, tiles resolve through `withBase()` from `v/<pub>/` and `/s/<pub>/tiles/`. **`sig-exports tiles verify`** runs the six K1 §9.2 checks — count conservation (z ≤ 9 Σ `n` = the compartment's published located records; z ≥ 10 the `rk` set in tile interiors = the published set for that tier range; 0 missing, 0 extra), renderer parity (pure-Python and tippecanoe agree on the `rk` set and Σ `n` per zoom; byte equality not required), precision/tier (no property outside `sig.map-tiles/2`; no claim ids, full-precision coordinates or personal data in any tag — §19.4/Part VIII), size (max tile ≤ 500 KB, warn at 200 KB), metadata (licence/attribution/bounds equal `index.json`; the archive's licence equals its compartment's) — writing `reports/tiles_verify.json` into the release candidate, and **CI builds pinned tippecanoe 2.79.0** from the Dockerfile's tarball once (cached) and runs the verifier on a **50k-point synthetic fixture** (clustered cities, co-located points, all tiers, 3 compartments), plus on dep P35.51's real-sized fixture in the nightly job. This row **writes ADR-156** (the map-v2 tile/basemap decision — reserved number, referenced provisionally by ADR-170) recording the retention scheme, the dual-renderer parity rule and the self-hosted-basemap direction it frames.
