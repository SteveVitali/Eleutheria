## Goal
Extend the populated graph to **gunshot detection**, **drones**, and **commercial location data**
with **no schema change** (any required change is a Phase-1 defect, recorded as one). The acoustic
sensors and drones are **non-camera physical sensors**, which MUST be represented **without a camera
abstraction**.

## In scope — deliverables
1. **Gunshot detection** populated as acoustic **PhysicalAssets that are not cameras** (`asset_type` → an `acoustic` Technology; already present in OSM as `gunshot_detector`) — SIG-ONTO-027.
2. **Drones / UAS** populated as airborne PhysicalAssets (`mobility=airborne`), not a camera abstraction — SIG-ONTO-027.
3. **Commercial location data** populated as a `data-acquisition` **Deployment/DataSystem with no locally owned sensor** (a subscription is a deployment with no roadside device) — SIG-ONTO-026, SIG-ONTO-031.
4. A **Phase-1-defect record** path if any of the above requires a schema change.

is a population task against the existing schema, not a modelling task. Coordinate sensitivity for a
