# P27.5 — Web data layer: wire all public pages to the export (P27)

- **Semantic id:** `LAUNCH.5` · **Phase:** 27 · **Kind:** ticket · **Tag:** p27-launch
- **base_branch:** `devin/p27-4-spine-backed-export-bundle` · **Depends on:** P27.4 (the export artifacts these pages read)
- **Run:** `implement-spec spec=docs/tickets/P27.5__web-data-layer-wiring.md`
- **Gate status:** engineering — pure `web/` change; **zero-JS content preserved** (no islands here — that's P27.9).

## Goal
Extend the single build-time data seam (`web/src/lib/data.ts`, ADR-066) so **every** public surface
reads real export bytes under `SIG_DATA_SOURCE=export`, not committed fixtures — closing the gap where
the map/network/freshness/coverage/watch/evidence/corrections/research-queue pages are fixtures-only.

## Load (cite; do not copy)
- `docs/2_canonical_design_spec.md` §15 (web shell), SIG-UI-036/037 (static-first, zero-JS), ADR-066 (the fixtures|export switch).
- Code: `web/src/lib/data.ts` (extend), `web/src/lib/*-fixture.ts` + `map.ts`/`network.ts`/`metrics.ts`/`watch.ts`/`research-queue.ts`/`corrections*.ts`/`evidence-viewer.ts` (the shapes), `web/src/pages/*` (the consumers), P27.1 contracts, P27.4 `exports/out/*`.

## In scope — deliverables
1. **Extend the data layer.** Add typed getters mirroring the P27.1 contracts —
   `getMapSites`, `getNetwork`, `getFreshness`, `getCoverage`, `getWatch`, `getEvidence`,
   `getCorrections`, `getResearchQueue`, `getDossierIndex` — each `fixtures` (committed sample) |
   `export` (`<exportDir>/web/<artifact>.json` from P27.4), **failing LOUD** in export mode if an
   artifact is missing (never silent fall-back — that fabricates green).
2. **Convert the pages.** Repoint `map.astro`, `network.astro`, `reference-map.astro`,
   `reference-graph.astro`, `data-freshness.astro`, `coverage-metrics.astro`, `watch.astro`,
   `evidence/*`, `corrections.astro`, `research-queue.astro`, and `dossier/*` off direct fixture
   imports and onto the data layer — no page reads a `*-fixture.ts` directly.
3. **National scale.** Where a page now renders thousands of rows (freshness = 210 sources; map table =
   tens of thousands of sites), add build-time pagination/summarisation so the static HTML stays within
   the a11y/perf budget (detailed table shapes finalised in P27.7).
4. **Keep both modes green.** Fixtures stay the CI default; the e2e/a11y suite passes in **both**
   `fixtures` and `export` modes (as P21.4 established for dossiers).
5. **Records:** `docs/build/runs/P27.5.md`, PR body.

## Out of scope
- Any client JS / island (P27.9); nav/IA/landing redesign (P27.6); visual polish + empty-state design
  (P27.7); changing the export artifact shapes (P27.4 owns them).

## Acceptance criteria
- [ ] every public page reads through `data.ts`; a grep shows no page importing a `*-fixture.ts` directly *(deterministic)*
- [ ] `SIG_DATA_SOURCE=export` renders real P27.4 bytes on all surfaces; a missing artifact fails the build loudly *(deterministic)*
- [ ] `npm --prefix web run check` passes in BOTH fixtures and export modes (typecheck, unit, build, licenses, e2e incl. axe WCAG 2.2 AA) *(deterministic)*
- [ ] zero-JS budget holds (script bytes 0, ≤150 KB) on every public page; large surfaces paginate/summarise at build time *(deterministic)*
- [ ] `make check` + build-memory green *(deterministic)*

## Cross-cutting invariants
Cited from `docs/tickets/00_MANIFEST.md § Cross-cutting invariants`: zero-JS on public pages (no
`<script>`); WCAG 2.2 AA; export mode fails loud, never fabricates; absence rendered as an honest gap,
not an empty guess; TypeScript stays inside `web/`.
