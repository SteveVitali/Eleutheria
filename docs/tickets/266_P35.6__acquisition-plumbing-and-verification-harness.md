## In scope (deliverables)

1. **Registry/target/cadence generator** — consumes the plan CSV's Round-11 rows and emits `sources.toml` rows (all `ingestion_permitted=false`), target rows and `ops/cadence.toml` batch rows. Enforces R2 id rules: `<prefix>_<place>_<channel>`, ≤ 40 chars, lower snake case, family prefixes (`camreg_`, `dot_511_`, `procportal_`, `statrep_`, `ccops_`, `policy_`, `grant_`, `agenda_`, `legis_`); rejects any id that is a prefix of another id or collides with the 342 registered ids, and rejects a dataset id already present in `sources.toml` or the targets files (I7 NEW-1, I8 NEW-5).
2. **Batch generator (I8 NEW-4)** — emits the wave batch rows (`r11-layers-01/02`, `r11-ate-01`, `r11-procurement-01`, `r11-disclosures-01/02`, `r11-documents-01`, `r11-tier2-01…03`) with the §7.1 crons; the `unscheduled_live_sources` guard must pass on the emitted set.
3. **First-run safety (R6)** — `scheduled-ops.sh --paused` creates triggers paused; per-row `task_timeout` (6h for documents/layers batches; legistar rises 60m → 3h when P35.8 widens it); `--max-retries 0` rows resume by `logical_run`.
4. **Field denylist + `out_fields` allowlist (F-330, I8 NEW-3, P8-5)** — a schema-enforced denylist (plate/red_vrm/hotlist/search reason/first_name/last_name/email/phone/address and kin) rejects any ArcGIS/Socrata target whose layer fields match; the `out_fields` allowlist replaces `outFields=*` for new camera targets so raw captures hold only allowlisted fields; `api_allowlist.toml` rpm applied to `dot_511` targets.
5. **`coverage-delta` CLI** — I1's blind-spot method as a committed, read-only tool (per blind spot, tier-A/B state, GL1 city, technology class, country); never uses `/v1/coverage` as volume evidence (I8 §7.7).
6. **Wave-verify CLI** — the §7.7 per-source checks as one command: review-status green after the HG-03 line; captures landed (bytes in the OCFL store, not digest-only); run row `ok`; claims > 0; +0 re-run (`claims_added == 0`); 0 ALPR/ATE subjects without a `technology` claim and 0 new `traffic_camera`-only typings; jurisdiction key (`iso.3166_2`, plus GEOID where sub-state) set on every target.
7. Tests under `tests/ops`/`tests/connectors`: generator id rules (collision, prefix, >40 chars, dataset dedupe), emitted cron lint-cleanliness, `--paused` path, `task_timeout` emission, denylist accept/reject fixtures (incl. the F-330 archetypes), `out_fields` replacement, coverage-delta and wave-verify output shapes.
