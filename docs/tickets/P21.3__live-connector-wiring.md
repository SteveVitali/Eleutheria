## In scope — deliverables
1. **`HttpxTransport`** (`connectors/src/connectors/transports/httpx_transport.py`): implements `Transport` over `httpx` (already a dev dep — promote to a `connectors` runtime dep in `pyproject.toml` + lockfile via `uv add`); honours `PoliteFetcher` (per-host rate limit, `robots.txt` cache, conditional GET/ETag, retry-with-backoff on 429/503 with `Retry-After`, **Overpass semantics**: 429/504 = back off and retry, not a challenge — LD-F03); user-agent string from policy (`policy.crawler` if present, else `SIG/<version> (+https://<homepage>)`); **never** follows the enumerated circumvention techniques (`assert_no_circumvention`). Unit tests against a local `httpx.MockTransport`/`pytest-httpserver`-style stub (no network in tests).
2. **`OcflCaptureStore`** adapter (`connectors/src/connectors/capture_ocfl.py`): implements the connectors' `CaptureStore` Protocol over `evidence.OcflStore`, storing raw bytes + headers + retrieval time; for HTML pages optionally a WACZ via the P02.2 Playwright path (flag `--wacz`); content-addressed ids match the evidence tiers (LD-F02/LD-H02: live-connector WACZ per run).
3. **Runner CLI:** `sig-connectors run --source ID --mode live|replay|shadow --sink pg|memory --dsn … --capture-dir …` — refuses in `live` mode unless `review-status` is fully green (exit 3 with the gate reasons; LD-X08 can never recur), then executes the eight stages, writing a **fetch record** (`docs/build/live_runs/<date>_<source>.json`: url list, status codes, bytes, capture digests, claim count, duration, rate-limit events) — no content in the record.
4. **Connector wiring:** `osm` (Overpass query for the OKC bbox surveillance tags → ODbL compartment table), `records` (MuckRock read-only listing with `SIG_MUCKROCK_TOKEN`; extraction stays off for released docs unless `ingestion_permitted`), `procurement` (USAspending sub-award query used in P07.3 — now *through* the gate), agenda (`okc_council` via CivicClerk `oklahomacityok` tenant — verify the tenant live, update `agenda_tenants.toml` note), `okc_procurement`/`okcpd_policy`/`ok_statute` as **document connectors** (fetch the cited PDFs/HTML from `okc_sources.json` `url`s, capture, parse via `sig-parsing`, emit the same claims the fixtures encode). Each keeps fixture replay byte-identical (`shadow_replay` diff = 0 for the fixtures).
5. **Isolation on the composed stack** (LD-X06): the isolation test set runs with `HttpxTransport` present and proves no DNS/socket escape outside the allow-list in `replay`/`shadow` modes.
6. **Run what is permitted:** for each source with green `review-status`, one live run into the composed PG (from P19.3/P19.4/P19.5 fixtures) — assert claims land via `PgClaimSink`, captures exist in OCFL, and re-running is idempotent. For sources not green: run `shadow` over fixtures and record the blocker.
7. **`docs/build/LIVE_WIRING_REPORT.md`:** per-source table (mode run, gate state, URLs count, captures, claims, contradictions surfaced, blockers), the rate-limit/robots evidence, and the exact env/commands; **ADR-065** (transport choice, capture adapter, gate-refusal semantics); risk register (`RISK-P21-04` live fetch cadence vs source etiquette → `cadence` field + Overpass backoff; `RISK-P21-05` token leakage → env-only + `.gitignore` `.env*` + a test that no `SIG_*_TOKEN` literal appears in the repo); traceability.
