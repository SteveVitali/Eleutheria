# P15.1 — Web shell + epistemic visual language

- **Sequence:** 35 of 46
- **Phase:** 15 — Public web surfaces
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1

## Goal
The Astro static-first (zero-JS-by-default, opt-in islands) web shell, and the **epistemic visual
language** every other Phase-15 surface consumes: the four-step support glyph, the four
independently-visible epistemic fields (no fused badge, no colour-only encoding, green never for
epistemic state), the single clickable absence hatch, and contested-value markers — plus the
WCAG 2.2 AA + no-JS baseline (tabular equivalent per map, list equivalent per graph) and
belief-pinned permalinks with a "cite this page" affordance.

## In scope — deliverables
1. **Astro static-first shell** — zero-JS-by-default framework with opt-in interactive islands; archivability is structural (breaking it requires an explicit greppable directive) — SIG-UI-036, SIG-UI-037.
2. **The epistemic visual language**, owned here and referenced by P15.2–P15.5:
   - four-step support **glyph** with accessible text equivalent + machine-readable evidence count + downgrade reason code — SIG-UI-003;
   - the **four epistemic fields** (§10.7) rendered independently visible; fused badge prohibited — SIG-UI-004;
   - **no colour-only** encoding (redundant glyph/texture/text channel) — SIG-UI-005;
   - saturated colour reserved for epistemic state/data; **green never for epistemic state** — SIG-UI-006;
   - **one absence texture** (hatch), the four absence kinds (§9.5) distinguishable within it, each **clickable → generates a research task** — SIG-UI-007;
   - **contested-value marker** persistent at every appearance (cell, tile, popup, API, export) — SIG-UI-008;
   - contradiction rendered as a value range with competing claims plotted (source/tier/date/link, different-quantity note) — SIG-UI-009.
3. **WCAG 2.2 AA + no-JS baseline**: automated a11y checks in CI; the shell's own components ship a **tabular equivalent for every map and a list equivalent for every graph** as the reference pattern later surfaces reuse — SIG-UI-037.
4. **Design-system guardrails**: every dependency OSI-licensed with the exclusion (CC-BY-NC / source-available / dual-BUSL) checked **in CI, not by memory**; performance budgets enforced in CI (build fails on regression) — SIG-UI-039, SIG-UI-041.
5. **Citation & permanence**: every page exposes a **belief-pinned permalink** and a "cite this page" affordance carrying the as-of pair and ruleset version; a citation made today stays reproducible after SIG corrects itself — SIG-UI-035 (SIG-TIME-008).

## Notes
This ticket **owns the epistemic visual language and the a11y / no-JS / archivability baseline** that
P15.2–P15.5 all consume — the glyph, the four independent fields, the single absence hatch, the
contested-value marker, the tabular/list-equivalent pattern, the permalink + citation affordance, and
the OSI-only + performance-budget CI gates. Later surfaces reference these components; they do not
redefine them. The local advocate is the design center (SIG-UI-002) — the register and print path are
driven from that choice, so keep the shell paper-friendly. Any change to the visual language after this
is an ADR, not an ad-hoc edit.
