## Goal
The layered parsing stack real records responses demand: file classification of mixed-format
archives before parsing, cheapest-sufficient extraction by layer, a mandatory locator on every
claim, `raw_value` preservation for values SIG cannot parse, versioned reason-code normalization,
and parser-drift detection.

- `docs/2_canonical_design_spec.md` §24 (document parsing and extraction: §24.1 layered strategy, §24.2 reason-code normalization, §24.3 parser drift).
- Part 0, Part I §3 (invariants), Appendix E glossary.

## In scope — deliverables
1. **Layered extraction** (structured import → selector/template → PDF text → PDF table → OCR → LLM-assisted → human), cheapest sufficient method, with the method recorded on the extraction — SIG-PARSE-001.
2. **File classification runs before parsing** and its verdict is recorded; mixed-format ZIPs (scanned faxes, password-protected PDFs, merged-header XLSX, multi-sheet native exports) are classified per member — SIG-PARSE-002.
3. **Mandatory locator** (page, bbox, cell, row, byte range, DOM path) on every extracted claim; a locator-less extraction is **rejected** — SIG-PARSE-003.
4. **`raw_value` preserved** before any typing/normalization, *including for values that fail to parse* (P2) — SIG-PARSE-004.
5. **Reason-code normalization** through a versioned, inspectable, reversible mapping stored as data; raw text retained; mapping version stamped on every claim; free-text vs constrained-dropdown reasons distinguished — SIG-PARSE-005, SIG-PARSE-006.
6. **Parser-drift handling**: committed fixtures (real captured input → expected output) per parser, plus a nightly canary against live sources that alerts on structural change — SIG-PARSE-007, SIG-PARSE-008.

## Out of scope (scope-creep guard — do NOT do these here)
- The `records`/`procurement` connectors that feed this stack — P07.2, P07.3.
- LLM extraction *policy* scaffolding (`model_id`/`prompt_version`/source-span validation, §25) beyond wiring layer 6 as a parser — the §25 guardrails are exercised by the connectors that call them.
- Snapshot-diff at the extracted-field level — P08.2 (§29.7).

## Acceptance criteria (from the Phase 7 ACs, sub-set to this ticket)
- [ ] Every extraction emits a locator; locator-less extractions are rejected. *(deterministic)*
- [ ] `raw_value` is preserved for unparseable values (round-trip test on a value SIG cannot type). *(deterministic)*
- [ ] Mixed-format archives are classified before parsing; the classification verdict is recorded per member. *(deterministic)*
- [ ] The reason-code mapping is versioned and reversible; changing it does not rewrite history, and the mapping version is stamped on the claim. *(deterministic)*
- [ ] Each parser has committed fixtures; the nightly canary alerts (not silently drops) on structural change. *(deterministic for fixtures; agentic for canary alerting)*
