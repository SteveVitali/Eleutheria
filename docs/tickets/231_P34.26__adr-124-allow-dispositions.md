## In scope — deliverables

1. **`sig-ops disposition` verb** (G2 Step 1 preconditions): `record --allow --from <list> [--dry-run (default) | --apply] --authority <ADR-159 rule + registry id> --decided-by <role>`; INSERT-only through `db.dispositions.record_disposition`; refuses an organisation without a tier 0–1 registry match record, refuses any that fails the person-name screen (run on the label, the matched registry name and the literal party values, K2 §3.4), refuses persons always (ADR-163), and never writes `UPDATE`/`DELETE`. `--decided-by` names a role or the ADR-159 rule, never a personal name. *(SIG-TRUST-006, SIG-PUB-002, SIG-STORE-011)*
2. **Read-only census** (committed report `docs/build/reports/p34.26-flagged-org-census/CENSUS.md` + CSV): every organisation with `publication_review_required` — degree, edge share, which external identifiers it already carries (Census of Governments id, SAM UEI, Wikidata QID — recorded only from `ingestion_permitted` sources, ADR-159 item 6), person-name screen result (as a count; screened labels are never written to a committed file), and its ADR-159 outcome (eligible for auto-allow / "not yet reviewed"). Run on the fixture spine in CI and once read-only on `sig-pg` (the leg). K2 NEW-1's "969 flagged" and "50 reviews unlock 96.5 %" are re-measured, never pinned. *(SIG-TRUST-006, SIG-ONTO-013)*
3. **Typed state:** a test proves an organisation without an `allow` is served by the API gate as the typed `pending_publication_review` absence ("not yet reviewed"), and one with an `allow` recorded through the verb is visible (fixture). *(SIG-TRUST-006)*
4. **The owed DEFERRALS row** for the ADR-124 allows: created by SEED-14 (T4; Stage-B carry) — this row appends its evidence annotation (verb + census) to it; if it does not exist at dispatch, this row appends it (`owner:` P34.46 / P37.46a/b, `trigger:` the Round-10 schema deploy), never a cell edit.
