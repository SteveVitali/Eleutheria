# P10.1 — The research-task engine

- **Sequence:** 24 of 46
- **Phase:** 10 — Research-task generation
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1

## Goal
The task-coordination **engine**: the detector specification language (tasks as data with a testable
closing condition), the task lifecycle with auto-invalidation, the full disposition vocabulary
including "searched, found nothing", geographic queues, the anti-abuse rules, and the SIG-owned
local-group registry. The concrete detector *catalog* is P10.2.

- Always-in-scope context: Part 0, Part I §3 (invariants), Appendix E glossary.

## In scope — deliverables
1. **Detector specification language** — every task type declared as data with `task_type`, versioned `detector` query, `priority_fn`, testable `closing_condition`, `assignee_class`, `effort_estimate`, `dispositions[]`, `geographic_scope`; a type with no testable `closing_condition` is refused registration — SIG-TASK-001/002.
2. **Lifecycle** — `generated → triaged → claimed → in_progress → submitted → verified → closed` with `reopened`/`invalidated`; tasks **auto-invalidate** when their detector no longer fires (evidence arriving by another route silently closes them); duplicate suppression by `(task_type, subject)`; claim timeout returns abandoned claims to the pool — SIG-TASK-005/006/007.
3. **The disposition vocabulary** richer than "done" (`resolved_evidence_found`, `resolved_no_evidence_exists`, `blocked_access_denied`, `blocked_fee`, `blocked_awaiting_response`, `not_actionable`, `superseded`, `deferred`); `resolved_no_evidence_exists` is wired to write a `CoverageRecord` (`absence_kind = searched_not_found` + sources searched) so the queue can shrink — SIG-TASK-008/009. *(The records-request path that exercises this is P10.3.)*
4. **Geographic queues** — a local group MAY claim a jurisdiction (visibility, notification, queue priority) but claiming grants **no exclusivity**; claims expire without renewal and any contributor may work any open task — SIG-TASK-010/011.
5. **Anti-abuse** — no volume leaderboards; recognition qualitative and tied to verified contributions; task generation rate-limited per subject so one badly-modelled entity cannot flood the queue — SIG-TASK-012/013.
6. **The SIG-owned local-group registry** — name, jurisdiction, URL, contact, activity status, claimed queues — not dependent on any external directory's availability — SIG-TASK-014.

## Notes
This ticket **owns** the detector-as-data contract, the task lifecycle/disposition vocabulary, and the
local-group registry — P10.2 (the catalog), P10.3 (records-request generation) and every contributor
surface build on them. The `closing_condition` discipline (SIG-TASK-002) is load-bearing: "research
this" is not a task. Geographic claiming is a coordination affordance only; its expiry (SIG-TASK-011)
is the safeguard against territorial gatekeeping and must not be softened.
