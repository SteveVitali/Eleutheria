## Goal
Ingest the Flock **audit-export** structural layer — the agency audit CSVs — as **aggregates and
configured edges only** (never per-search or per-plate rows): `Camera Count` as an independent count
claim, `SharedNetworks.csv` as configured sharing edges through P08.2's reconciler, `***` redaction

## In scope — deliverables
1. **`audit_structural` connector** parsing the agency audit exports into **structural aggregates only** — no per-search or per-plate row is created anywhere (§18.1) — SIG-INGEST-046.
2. **Audit `Camera Count`** lands as an **independent count claim** (its own predicate, reconciled against other counts by P08.2, never merged into them) — SIG-INGEST-035/046.
3. **`SharedNetworks.csv` sharing edges** land as **configured access only, directional, blank cells as negatives**, single-snapshot edges carrying `valid_from_kind='unknown'`; asymmetry/finding emission runs **through P08.2's §29.3 reconciler (owned there)** — SIG-ONTO-042/044.
4. **`***` redaction distinguished from empty** — a redacted cell is a distinct, recorded state, never conflated with a missing/blank value — SIG-INGEST-046.
5. **The four audit source types** recorded and treated as **non-interchangeable** (each carries its source-type provenance; they are not silently unioned) — §23.7 constraint.
6. Audit-derived `UsageAggregate` rows are **landed into the boundary P12.1 builds** (the entity is minted in the ontology at P01.1); this ticket writes the aggregates, it does not build the DuckDB/Parquet substrate.
