## Interfaces and collision surface

- The classifier consumes **V14's emitted deltas** (row 335) + the §7.2 named triggers (first release of a compartment/ever, allow-list change, new source/source-type, licence change, any failure/waiver, ratchet regression, disclosure-set change) — it reads results, never re-derives them.
- The **template fingerprint** is a digest of a fixed-fixture build of the same commit — the drift check is deterministic, recorded in the release metadata and the readout.
- The **standing go** is a record with adopted text + expiry + void conditions — the tooling *validates* it (present, unexpired, unbreached, in-scope); adoption, amendment and voiding are operator acts; expiry or breach → next Class R needs a signed readout.

- `live:` edges: none — the classifier and readout run inside the release rows' promote path; the standing-go adoption is the operator's recorded act.
