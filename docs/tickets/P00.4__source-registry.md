# P00.4 — Source registry, seeded

- **Sequence:** 4 of 46
- **Phase:** 0 — Foundations, governance, ecosystem coordination
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P00.2 (uses its rights/licence model and the `ingestion_permitted`/export-gate rules)
- **Run:** `implement-spec spec=docs/tickets/P00.4__source-registry.md`

## Goal
Seed the source registry with every source in OL-21 and §22.3 as executable data: each row carries a
rights record, an SPDX expression, a **separately reviewed** `redistributable`, a custody posture, a
`compact_status`, and `ingestion_permitted` defaulting to **false** — and the Stage-0 outreach outcomes
(including `no_response`) are recorded.

## Load
- `docs/2_canonical_design_spec.md` §22 — esp. §22.2 (the verified access matrix), §22.4 (compact &
  enforcement), §22.6 (the seeded registry rows); plus §22.3 (sources the outline does not name) and §22.5 (Eyes on Flock).
- Part 0, Part I §3, Appendix E glossary. Rights-record shape is P00.2's licence model (§42.1).

## In scope — deliverables
1. **Registry schema + seed** carrying every §22.6 row and every §22.3 addition, each with the
   SIG-INGEST-023 minimum fields — SIG-INGEST-038.
2. **Rights record per source**: SPDX expression, attribution, **separately reviewed** `redistributable`
   (never derived from the licence string), archived terms text — SIG-INGEST-023/024, SIG-LIC-001/003.
3. **`ingestion_permitted` defaulting to false** as a runtime gate the connector loader honours — SIG-INGEST-028, SIG-CHART-032.
4. **`compact_status`** as a closed vocabulary including **`no_response` as a recorded state**, seeded from
   Stage-0 outreach outcomes recorded out-of-band — SIG-INGEST-027/029.
5. **Eyes on Flock** row with its Stage-0 outreach outcome recorded (the Phase 11 blocker) — SIG-INGEST-030.
6. **Canonical DeFlock host resolved** to `deflock.org` (not `deflock.me`), and the **local-group registry**
   seeded (incl. `eyesoffcr.org`) — REQ-R1-14, SIG-TASK-014.

## Out of scope (do NOT do here)
- Authoring the rights/licence model or the export gate — P00.2 owns those; this ticket *populates* them.
- Writing any connector, or actually fetching from any source — Phase 4+. Verifying still-unverified rows
  is a data-entry/research task, not connector work.
