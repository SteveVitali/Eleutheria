## Goal
GL-GATE-08: robots verdicts stop gating fetches — the operator accepts the
weakened never-bypassed audit property and the egress-IP-block exposure on
shared vendor infra. Implementation rule recorded at the disposition: the
robots verdict is still **probed and recorded** per-target (the audit trail
keeps its evidence) but **never blocks** a fetch. This ungates primegov's
110 `Disallow:/` hosts, `ok_statute`, and every robots-refused catalog row.

## In scope — deliverables
1. **ADR** — a new ADR superseding ADR-087's enforcement layer: robots
   verdict recorded, never enforced; rationale = operator disposition;
   honest revisit trigger (egress-IP block observed, counsel objection, or
   the audit-value assessment changes). RFC 9309 4xx handling stays.
2. **Code.** the politeness/fetch layer: robots probe still runs + its
   verdict lands in the fetch record, but `Disallow` no longer refuses.
   The recorded outcome vocabulary gains a `robots_disregarded` marker so
   the audit trail stays honest — a claim's provenance says the fetch
   ignored a refusal.
3. **Re-sweep.** every source whose only blocker was robots: primegov's
   110 tenant hosts (the P26.5 enumeration artifact), `ok_statute`,
   robots-refused rows from the P26.13 catalog batch, civicclerk/escribe/
   legistar refused hosts. Each re-attempted; honest outcomes (some will
   fail anyway — WAF/403s are not robots; recorded as such).
4. **Hosted runs** for the newly-yielding sources; jobs + schedulers;
   spine delta; idempotent re-run.
5. **Records.** ADR + deferral updates (`D-SOURCES.2-4` primegov leg);
   live_runs/ + GCS run rows; ladder re-measured.
