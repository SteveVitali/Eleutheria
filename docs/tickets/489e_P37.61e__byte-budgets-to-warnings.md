## Goal — RULING E-4 verbatim

"Write an ADR amending this repo's B3 §6 contract bounds:
- Byte budgets become **warnings**, not failures. That covers the 48 KiB orient recipe, the ledger head budget, the per-entry 2 KiB PHASE LOG budget, and the notes-file budget that has needed 'slide line' and compaction commits.
- Keep the **shape** checks hard:
  - CURRENT STATE key order and vocabulary;
  - keys outside the block;
  - `| PRIOR`;
  - returnPass shape;
  - ≤256 B per CURRENT STATE line.
- Keep one generous hard ceiling: the CURRENT STATE block plus the ledger head stay ≤ 18 KiB, so they remain readable in a single ~20 KB agent read.
- If a check id currently bundles a byte budget with a shape check (as upstream `ledger-budget` does), split the id first, so no shape check is downgraded by accident.
- Apply the same change to the matching SIG-LOCAL hunk (L5) in `scripts/docs/check-build-memory.sh`, and keep `memory_guard.py` consistent.
- Never 'fold' or rotate text to meet a budget unless the fold archives every clause it drops.
