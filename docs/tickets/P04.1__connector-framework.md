## Goal
The reusable connector substrate every source adapter plugs into: the eight-stage interface with
`fetch()` as the only network-egress stage, the shared rate-limiter/robots layer, the loader-level
licence/compact gate, network-isolated replay, shadow-mode diffing, and source-disappearance as
first-class events. **Write no source-specific connector here** — OSM and Atlas are P04.2/P04.3.

## In scope — deliverables
1. The **eight-stage interface** (`discover→fetch→capture→parse→extract→normalize→link→load`), separately addressable/retryable, each stage content-addressed — SIG-INGEST-001; every stage runnable as a plain CLI per the P00.1 convention.
2. `fetch()` as the **only** stage with network egress; every post-`capture()` stage a pure function of stored artifacts — SIG-INGEST-002; plus stage idempotency — SIG-INGEST-003.
3. **Shared rate-limiter + robots layer** with per-host budgets, a contact-carrying UA, crawl-delay honoring; connectors hold no HTTP client of their own — SIG-INGEST-011; robots-unretrievable ⇒ refuse to run — SIG-INGEST-012; no challenge-defeating crawler — SIG-INGEST-013.
4. **Connector-loader gate**: check `ingestion_permitted`, `custody_posture`, and `compact_status` **before** any fetch and refuse when permission is absent/unresolved — SIG-INGEST-014, SIG-INGEST-028; export compatibility computed per compartment and the build fails on incompatibility — SIG-LIC-010.
5. **Source disappearance as data**: a 404/removal/persistent-challenge writes a first-class event row and a research task, never a swallowed exception — SIG-INGEST-009/010.
6. **Backfill + replay + shadow mode**: replay runs against archived captures in a network-isolated context, and shadow mode diffs the new claim set against the current one and reports the delta before asserting — SIG-INGEST-017/018/019; lineage recorded per `ingest_run` and mapped to PROV-O — SIG-INGEST-015/016.

## Acceptance criteria
- [ ] A network call after `capture()` **fails the run** (replay in a network-isolated context). *(deterministic)*
- [ ] Replay over pinned capture digests produces byte-identical claims modulo generated id and `sys_period`. *(deterministic)*
- [ ] Shadow mode reports a claim-set diff **without asserting** the new claims. *(deterministic)*
- [ ] A source returning 404 produces an event row **and** a research task, not an exception. *(deterministic)*
- [ ] `robots.txt` unretrievable ⇒ the connector refuses to run. *(deterministic)*
- [ ] The loader refuses to run a connector whose `ingestion_permitted`/`compact_status` denies ingestion; and an export that mixes incompatible licence compartments **fails the build**. *(deterministic)*
- [ ] **Phase-gate (§51.3):** CI green incl. data-quality checks; new requirements have automated tests (SIG-ENG-004); ADRs written for any deviation; traceability matrix updated; risk-register entries for this phase updated.
