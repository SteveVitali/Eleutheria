# P03.1 — Jurisdiction and Organization registries

- **Sequence:** 9 of 46
- **Phase:** 3 — Identity registry and deterministic ER
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P02.1 (registries are claim-spine entities with identity only)

## Goal
Stable identity before anything is counted: a Jurisdiction registry with temporally-versioned geometry and
an Organization registry, carrying the municipality/department distinction and temporal identity (merges,
splits, renames, dissolutions) as reified, time-bounded records.

  identity), §16 (canonical schema — identity-only entities).
- Part 0, Part I §3, Appendix C (DDL), Appendix E glossary.

## In scope — deliverables
1. **Jurisdiction registry**: first-class entity, self-referential (overlapping) hierarchy, pluggable
   national code systems, MultiPolygon boundary with `boundary_source`, and **temporally-versioned geometry** — SIG-ONTO-010/011.
2. **Organization registry**: the single entity for all institutional actors ("vendor" is a role, not a
   subtype), name/alias/identifier as sets, two-axis classification (`organization_class` × `operating_relationship`) — SIG-ONTO-012, SIG-IDENT-010.
3. **Municipality ≠ police department**: distinct organizations joined by `parent_of`; colon-named agencies
   parsed into parent + local unit — SIG-IDENT-009/011.
4. **Surrogate identity** for organizations with no external identifier: minted SIG id with an immutable
   `identity_basis`, and the `publication_review` routing for HOAs/small bodies — SIG-IDENT-012, SIG-ONTO-013.
5. **Temporal identity**: reified `OrganizationRelation` records (seven-value vocabulary) with valid + txn
   time; a **rename** produces a new version + dated alias, never a succession or new identifier; `status` vocabulary — SIG-IDENT-016/017/018.
6. **Registry-ingest guards**: fixed-width GEOIDs with explicit `level`; agency centroids barred from
   point-in-polygon use; a zero-record ingest **fails the run** — SIG-IDENT-005/004/008/006.

## Out of scope (do NOT do here)
