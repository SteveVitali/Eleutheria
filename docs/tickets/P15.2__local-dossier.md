## In scope — deliverables
1. **Dossier sections in order** (§39.2): at-a-glance; what is deployed; cost and expiry; who else can see the data; configuration and retention; usage; where the hardware is; policy; accountability events; timeline; **what we don't know**; how we know this — SIG-UI-010.
2. **"What we don't know" as a headline feature**, not an appendix — present in the summary, the print export, and the API — SIG-UI-011.
3. **Incompleteness banner** naming the count of unresearched fields and stating that absence of a row is not evidence of absence — SIG-UI-012.
4. **Print/PDF path** producing a hand-to-a-council-member document: paginated, with sources, and the **as-of date + permalink on every page** — SIG-UI-013.
5. **Every material figure expandable to its reconciliation**: the rule that fired, competing claims, each source's tier and date, and a link to the document at the supporting page/cell — SIG-UI-014.
6. **The three action blocks** the outline omits — `authorization` (approving body, vote, consent-agenda flag, public comment, date), `termination_mechanics` (auto-renew flag, notice window, derived `next_decision_date`), `legal_regime` (state statute, local ordinance, disclosure duties) — SIG-UI-014a.
7. **`next_decision_date` computed and displayed wherever an expiry is displayed** (the decision date, not the expiry date), keyed so the renewal watch consumes it — SIG-UI-014b.
8. **Full Appendix B content contract**, rendering `unknown` values explicitly rather than omitting them — SIG-UI-015.
