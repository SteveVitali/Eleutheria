## Goal
Extend the populated graph to **facial recognition**, **cell-site simulators**, and **mobile-device
forensics** with **no schema change** (any required change is a Phase-1 defect, recorded as one).
These are **non-camera capabilities with no physical asset**, which MUST be representable without a
camera abstraction; and **federal authorization datasets** MUST populate `authorization_state` with
their **native validity intervals**.

## In scope — deliverables
1. **Facial recognition** populated as a `Capability` (`search.face.*`) searching against a reference **DataSystem** (image/reference gallery) with no locally owned sensor — SIG-ONTO-031, SIG-ONTO-023.
2. **Cell-site simulators** and **mobile-device forensics** as **Deployments with no product, vendor, or physical asset** — a capability with no roadside device — SIG-ONTO-026; capability slugs `locate.handset.rf`, `extract.device.logical/physical`, `extract.cloud.account` — SIG-ONTO-023.
3. **Non-camera / no-physical-asset representation**: none of the above is forced into a camera or generic-asset abstraction — SIG-ONTO-026/027.
4. **Federal authorization datasets** populate `authorization_state` (§13.4 track 4) with their **native validity intervals** encoded as EDTF, carried on the Deployment and/or a linked `LegalInstrument` — never coerced to a point value.
5. A **Phase-1-defect record** path if any of the above requires a schema change.
