# P14.1 — The public read API

- **Sequence:** 33 of 46
- **Phase:** 14 — API and exports
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P13.2 (predecessor), P08.1 (resolver / resolution envelope), P09.1 (coverage statement)
- **Run:** `implement-spec spec=docs/tickets/P14.1__public-api.md`

## Goal
A hand-written, versioned read API (FastAPI) that never returns a bare value: every material fact
carries its full resolution envelope, both as-of parameters are accepted and echoed, belief-pinned
requests are reproducible after a correction, every ID is dereferenceable at `/id/{type}/{uuid}` with
content negotiation, a `/changes` feed exists, access tiers and anti-misuse terms are enforced, and no
prohibited endpoint exists.

## In scope — deliverables
1. **A hand-written, versioned API** (FastAPI + OpenAPI generation), never a schema reflection — SIG-API-001; the §37.3 resource families (`/entity`, `/claim`, `/resolution`, `/evidence`, `/dossier`, `/search`, `/task`, `/coverage`, `/contradiction`, `/crosswalk`, `/export`, `/changes`) — SIG-API-007.
2. **Full resolution envelope on every material fact** (`value`, `resolution_status`, `support`, `agreement`, `currency`, `rationale`, `supporting_claim_ids`, `dissenting_claim_ids`, `as_of_world`, `as_of_belief`, `ruleset_version`); a bare value is never returned — SIG-API-002. Plus a per-response **coverage statement** — SIG-API-003 — and a computed **licence statement** + upstream attribution — SIG-API-004.
3. **As-of semantics**: every read endpoint accepts `as_of_world` and `as_of_belief`, defaults them explicitly (never implicit "latest"), and echoes the resolved values back — SIG-API-005; responses cacheable by the full as-of pair, belief-pinned served long-cache, `now`-pinned not — SIG-API-006.
4. **Dereferenceable identifiers** at `/id/{type}/{uuid}` with content negotiation to HTML, JSON-LD, and RDF — SIG-API-008; the **`/changes` feed** driven by the snapshot-diff layer (§29.7) — SIG-API-009.
5. **Access tiers + anti-misuse**: anonymous / registered / partner tiers, none granting `restricted` or `sealed` through the public API — SIG-API-011; acceptable-use terms prohibiting re-identification with a stated remedy — SIG-API-013.
6. **The prohibited-endpoint bar**: no real-time device-liveness signal; no per-person lookup; no `sealed` capture bytes; no coordinates finer than the asset's sensitivity tier permits — SIG-API-012.

## Out of scope (scope-creep guard — do NOT do these here)
- Bulk exports, licence computation, ODbL split, crosswalk export, Zenodo deposit — P14.2.
- GraphQL as a secondary surface (SIG-API-010 SHOULD) unless trivially free; it MUST NOT be the only surface.
- Public web surfaces that consume this API — Phase 15.

## Acceptance criteria (testable; from the Phase 14 Part X ACs, sub-set to this ticket)
- [ ] **No endpoint returns a bare value without its resolution envelope** — a contract test asserts every material-fact response carries the full §37.1 envelope. *(deterministic)*
- [ ] **Both as-of parameters accepted and echoed** — a test omits them and asserts the response states the resolved `as_of_world`/`as_of_belief` it used, never an implicit "latest". *(deterministic)*
- [ ] **A belief-pinned request is reproducible after a correction** — a test pins `as_of_belief`, applies a correction, and asserts the pinned request returns the identical pre-correction result. *(deterministic)*
- [ ] **No prohibited endpoint exists (SIG-API-012)** — a test asserts there is no device-liveness, per-person-lookup, sealed-bytes, or over-precise-coordinate endpoint. *(deterministic)*
- [ ] **Phase-gate (§51.3):** CI green incl. data-quality checks; new requirements have automated tests (SIG-ENG-004); ADRs written for any deviation; traceability matrix updated; risk-register entries for this phase updated.
