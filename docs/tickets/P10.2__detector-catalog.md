# P10.2 — The detector catalog

- **Sequence:** 25 of 46
- **Phase:** 10 — Research-task generation
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P10.1 (the detector DSL + lifecycle these detectors register against), P08.3 (the §31 contradiction detectors this catalog must each map to a task)
- **Run:** `implement-spec spec=docs/tickets/P10.2__detector-catalog.md`

## Goal
Implement the concrete **task catalog** of §33.2: every task type as a registered detector query with
a testable closing condition, and a mapping so that **every** §31 contradiction detector generates a
task. This is the data that turns P10.1's engine into a working research-coordination queue.

## Load (read these canonical sections — do not re-read others; SIG-ENG-001)
- `docs/2_canonical_design_spec.md` §33.2 (the task catalog — the enumerated task types, their detectors and closing conditions).
- Engine context: §33.1/§33.3 (via P10.1); §31 (the contradiction detectors, via P08.3).
- Always-in-scope context: Part 0, Part I §3 (invariants), Appendix E glossary.

## In scope — deliverables
1. **The full task catalog** — every task type enumerated in §33.2, each registered against P10.1's DSL with a versioned `detector` query and a **testable `closing_condition`**; a type that cannot express one is a catalog defect, not a TODO — SIG-TASK-003/004.
2. **Contradiction → task mapping** — every §31 contradiction detector is wired to a task type, so a live contradiction always surfaces as actionable work — SIG-TASK-004.
3. **Per-type detector fixtures** — each detector has a committed fixture proving it fires on a seeded positive and stays quiet on a seeded negative, and that it **auto-invalidates** (via P10.1's lifecycle) when the condition clears.

## Out of scope (scope-creep guard — do NOT do these here)
- The engine itself — DSL, lifecycle, dispositions, geo queues, anti-abuse, registry — **P10.1** owns §33.1/§33.3–§33.7.
- Records-request generation and statute templates — **P10.3** (§36).
- Contradiction *detection* logic — **P08.3** (§31); this ticket maps detectors to tasks, it does not re-implement detection.
