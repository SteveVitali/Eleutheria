## Goal
The `procurement` connectors — cooperative purchasing vehicles, USAspending, and agenda platforms —
plus the `FundingInstrument` entity and the agenda-platform tenant registry: cooperative piggyback
contracts set `parent_cooperative_contract`, and federal sub-awards are traced through USAspending to

## In scope — deliverables
1. **`procurement` connector(s)** writing `Contract`, `FundingInstrument`, `acquisition_channel`, quantities, renewal terms, and dated lifecycle transitions — SIG-INGEST (procurement).
2. **Cooperative vehicles**: piggyback contracts (Sourcewell, OMNIA, NASPO ValuePoint, BuyBoard, TIPS, HGACBuy, Equalis, GSA) MUST set `parent_cooperative_contract`; `acquisition_channel` is a required model element — SIG-ONTO-032.
3. **`FundingInstrument` entity** (funder ≠ operator ≠ purchaser): `funder`, `recipient`, `instrument_type`, `program_name`, `federal_award_id`, … — SIG-ONTO (FundingInstrument).
4. **Federal sub-awards**: USAspending sub-award data (not only prime awards) traced from a Byrne JAG / UASI grant to a local surveillance deployment via `federal_award_id` — SIG-ONTO-033.
5. **Agenda-platform tenant registry**: agenda platforms are per-tenant APIs, so build and publish the tenant registry the connector needs (§22.3) — SIG-INGEST (procurement).
6. **`artifact_type` additions** (`state_auditor_survey`, `warrant`, `procurement_aggregator_record`) and the paywalled procurement aggregator carried in the source registry under a `LINK` custody posture — SIG-INGEST-047.
