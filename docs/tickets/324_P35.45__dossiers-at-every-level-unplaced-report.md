## Goal

Every publishable jurisdiction gets a dossier, and every record that cannot be placed gets an honest report instead of a guessed home: **`group_by_key` roll-ups** along the `placement@1` chain produce dossiers at country, admin-1, county and place levels with the D-K4-3 thresholds applied verbatim (counties ≥1 record ≈ 2,482; places ≥10 ≈ 2,817 plus any place with non-site evidence; non-US admin-1 ≥10 ≈ 218; PR/VI under US per D-K4-4); **one `web/dossiers/<slug-path>.json` per dossier** (the monolith dies — at ≈5.6k dossiers it would be ~13–25 MB); `jurisdictionCode` set to the country A2 with the **conservative publication profile** for countries without an adapter (D-K4-7); the research-queue gap `subject_id` re-keyed to `jurisdiction:<jkey>`; the release-tree `jurisdiction/<slug-path>/` lists keyed by display slug path with `unplaced/` replacing `unresolved/` — **landed before ACT-24** (K4 NEW-6; the publish row P35.63); **`/dossier/unplaced/`** — the data-quality report with its verbatim honest header, the by-reason table (R1/R6/R7/R8 vocabulary), per-source top reasons and the `/corrections/` link — excluded from jurisdiction counts, "N jurisdictions" copy and the place facet; and the **US-located DBRight re-review list** emitted for E4 (K4 NEW-4 — this row emits, E4 decides). Build-time is measured (the P32.13 `measure_build` pattern — ≈17k files is the design's inference, not a promise).
