# P08.3 — Contradiction as a first-class object

- **Sequence:** 22 of 46
- **Phase:** 8 — Reconciliation engine and contradictions
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P08.1 (the resolver emits contradictions and `input_digest`; P08.2 workflows emit the contradiction types)
- **Run:** `implement-spec spec=docs/tickets/P08.3__contradiction-object.md`

## Goal
`Contradiction` as a first-class materialized entity with a lifecycle: an open contradiction can be
published as `unresolved_conflict`; a `blocking` one forces `UNRESOLVED`; resolution sets status
without deleting; and a full L3 rebuild from claims + ruleset + resolver version is byte-identical.

- Part 0, Part I §3 (invariants), Appendix E glossary.

## In scope — deliverables
1. **`Contradiction` materialized entity** with `subject_id`/`predicate_id`, `contradiction_type` (`value_disagreement`, `predicate_conflation`, `value_domain_mismatch`, `sharing_asymmetry`, `policy_configuration_divergence`, `temporal_impossibility`, `count_basis_mismatch`, `identity_ambiguity`, `undeclared_copying`), `claim_ids[]`, `severity`, `status`, resolution fields, and `research_task_ids[]` — SIG-RECON-053.
2. **The lifecycle**: `status ∈ {open, under_research, resolved, accepted_unresolvable, superseded}`; `accepted_unresolvable` is a legitimate terminal state — SIG-RECON-056.
3. **`severity = blocking` forces `UNRESOLVED`** (`U7`) — the manual brake that stops publication without deleting anything — SIG-RECON-054.
4. **`unresolved_conflict` is publishable**: an open contradiction surfaces via the resolution's `contradiction_state` and the API, not hidden — SIG-RECON-055.
5. **Resolution does not delete**: a resolved contradiction remains visible in history; resolution sets status only — SIG-RECON-055.
6. **Byte-identical L3 rebuild**: resolutions (and their contradictions) are reproducible from `(claims + ruleset_version + resolver_version + as_of pair)`, verified by the stored `input_digest`; CI regenerates a sample and asserts a match; never edited in place — SIG-RECON-019/020/021.
7. **Detector→task contract**: every contradiction detector emits a research task with a defined closing condition — SIG-RECON-057.

## Out of scope (scope-creep guard — do NOT do these here)
- The resolver / ambiguity test that decides `U7` — P08.1 (§28); this ticket owns the `Contradiction` object the brake reads.
- The per-workflow detectors that raise contradiction types — P08.2 (§29); this ticket materializes and gives them a lifecycle.
- The research-task lifecycle/DSL that consumes `research_task_ids[]` — P10.1 (§33); this ticket only emits the task with its closing condition.
- The public read API surface shape — P14.1; this ticket asserts `unresolved_conflict` *is* exposable, P14.1 owns the endpoint.
