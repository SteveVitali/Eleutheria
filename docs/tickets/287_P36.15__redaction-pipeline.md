## Goal

Wire the redaction pipeline end to end. `redact()` (`evidence/src/evidence/redaction.py:43`) already builds a `RedactedCapture` derivative (parent link, method, version, digest) but has **no non-test caller**, there is **no review record**, and excerpt surfaces do not read the derivative — `tiers.py`'s `public_representation` returns a `public` capture's excerpt **raw**. This row lands: a callable pipeline that produces the derivative capture with an append-only review record; **irreversible text-layer removal** (the redacted spans are physically absent from the derivative's bytes — never overlay boxes on extractable text, the recurring failure mode SIG-PUB-016 names), proven by an extraction test; and every excerpt surface (tier view, API, dossier/export, web) sourced from the derivative — never the parent bytes.

## Interfaces and collision surface

- `evidence/src/evidence/redaction.py` — `redact()` gains its production caller; the signature (parent id, redacted bytes, method, version) is the pipeline's core. The **text-layer removal** is the new piece: for a document capture the redacted spans are removed/substituted in the derivative's bytes such that text extraction on the derivative cannot recover them.
- `connectors/src/connectors/capture_ocfl.py` — the derivative is written as a **new** OCFL object (the parent's bytes are write-once and never touched); `parent_capture_id` links the pair.
- `evidence/src/evidence/tiers.py` — `public_representation`: a redacted capture's `excerpt` comes from the derivative's content (or stays the `[redacted]` literal for `restricted`); a `public` capture with a redaction derivative serves the **derivative's** excerpt, never the parent's raw excerpt. `bytes_available`/`sealed` behaviour unchanged.
- `api/src/api/routes.py` / `models.py` — the capture/excerpt responses read through the same tier view; no route reaches parent bytes where a derivative exists.
- `exports/src/exports/dossier.py` — dossier excerpts are sourced from the derivative.
- The **review record** — an append-only record of the redaction decision (what was redacted, method, version, reviewer role — never a personal name, Part VIII; `date -u` stamps), reusing the review/decision record mechanism the curation surfaces own; re-confirm the exact store at build time against `db/`'s review tables. A redaction without a review record is a pipeline error, not a silent pass.
- Downstream consumers already named: P36.74 (row 289 — Flock portal probes redact SIG-PUB-002 material **in memory before persistence**, ADR-185) and P36.76/77/78 (11C) depend on this row; the in-memory-before-persist screen and the stored-derivative path are distinct and both bind.

## In scope (deliverables)

1. **The wired pipeline** — a real (non-test) caller drives `redact()`: a capture flagged for redaction produces the `RedactedCapture` derivative, written as a new OCFL object with `parent_capture_id`, `redaction_method`, `redaction_version` and digest; the parent is never modified.
2. **The review record** — every redaction lands an append-only review record (scope, method, version, reviewer role, timestamp); a redaction attempted without one fails loudly. No redaction is self-approved.
3. **Irreversible removal + extraction test** — the derivative's text layer physically omits the redacted spans; a test extracts text from the derivative and asserts the redacted strings are absent (the PUB-016 acceptance: no overlays on extractable text). `redact()` keeps refusing a missing method or version.
4. **Excerpt re-sourcing** — `tiers.py` `public_representation`, the API excerpt surface and the dossier/export excerpt all serve the derivative where one exists; a test asserts the raw parent excerpt never reaches a public representation once a derivative exists.
5. **Reviewable + re-doable** — the method/version record makes a mis-redaction identifiable; a re-redaction is a *new* derivative (new capture, new review record), never an edit — the §45.2 replace-in-place outcome works on the release artifact, and both facts stay true.
6. **Requirement stamps** in the PR body: `SIG-PUB-015`, `SIG-PUB-016` + the cited ids.
