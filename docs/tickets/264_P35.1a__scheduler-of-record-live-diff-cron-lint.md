## Goal

Make Cloud Scheduler — realised from `ops/cadence.toml` by `ops/gcp/scheduled-ops.sh` — the declared, reconciled scheduler of record; build the read-only `sig-ops live-diff` drift detector (job/service/identity/bucket-policy vs repo declarations); land the cron lint that rejects the dom⊕dow OR-semantics bug class; and enforce SIG-SEC-008 digest pinning across services *and* jobs. A drift is a loud failure, not a silent divergence.

## In scope (deliverables)

1. **Scheduler of record declared** — `ops/cadence.toml` is the single source: every `[[sources]]`/`[[batches]]`/`[probes]`/`[[maintenance]]` row maps to a Cloud Scheduler trigger; the GitHub Actions `schedule:` in `reingest.yml` is removed (repo-side; the `gh workflow disable` step is the operator's) with a **new ADR superseding ADR-076's scheduling path** (never fix it with a DSN secret — that would double-ingest next to Cloud Scheduler and move egress onto GitHub IPs). Dagster (`orchestration/`, ADR-016) is not a scheduler of record.
2. **`sig-ops live-diff`** — read-only (`gcloud … describe/list` only) reconciliation emitting `DRIFT <kind> <name>: repo=… live=…` and exiting 1 on drift, comparing:
   - each cadence row ↔ its Scheduler job (cron, time zone, target, state, invoker SA);
   - each Cloud Run job ↔ its row (image digest vs the roll record or declared pin, `SIG_OPS_CADENCE` digest vs repo, timeout, service account, secrets by name);
   - Run jobs without a row ↔ a new `[manual_jobs]` allow-list (declared-manual jobs like `sig-export`, `sig-materialize`, `sig-replay-ingest`);
   - services (digest, SA, invoker bindings) and bucket policies (versioning, retention, IAM) ↔ declared posture.
3. **Cron lint** — `cadence --check` (or `live-diff --lint`) rejects crons where *both* day-of-month and day-of-week are restricted (cron OR semantics: it fires on both) unless the row sets `cron_or_semantics_ok = true`; it also checks the declared `cadence` ("weekly"/"monthly") matches the cron's fire count over a sample year. The known offenders are labelled: `sam_gov` `0 5 1 * 1`, `openstates` `0 5 2 * 2`, `congress_gov` `0 5 3 * 2`, `eyes_on_flock` `0 5 23 * 0` — the lint flags them; the live fixes are P35.1b's sweep.
4. **Digest-pinning enforcement (SIG-SEC-008)** — live-diff reports digest spread and any tag (`:latest`) reference across services and jobs; a deliberate pin (e.g. `batch-05` on `feff986c` for D-P31.4-1) is declared in `cadence.toml` with `reason` + `expiry`; an undeclared tag/digest drift fails the check.
5. **Drift alarm** — `sig-probe` runs `live-diff` daily and alerts on any drift via the P34.4 alert path.
6. **In-ticket production write** — after OM-20 listing: deploy `scheduled-ops` (Scheduler state reconciled from the TOML, including the inert `[[maintenance]]` monthly-export trigger that stays gated on D-P34.6-2's verbatim go) and run the first live-diff.
7. Tests under `tests/ops`: live-diff parsers against fixture `gcloud` output, cron-lint accept/reject cases (dom⊕dow, annotated exceptions, cadence-vs-fire-count), pin-declaration schema, `[manual_jobs]` matching, DRIFT output format and exit codes.
8. Requirement stamps in the PR body: `SIG-OPS-005`, `SIG-SEC-008`.
