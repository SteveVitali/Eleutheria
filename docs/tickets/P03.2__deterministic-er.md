## Goal
The deterministic, explainable half of entity resolution: the per-class identifier crosswalk, a pure
versioned `normalize_org_name()` with committed test vectors, the auto-writing cascade tiers 0–3, and
public `sig:` identifier minting with stable-across-cluster-change merge/split events and tombstones.

## In scope — deliverables
1. **Identifier crosswalk**: per-class canonical scheme (ORI9, GEOID, GNIS, NCES, IPEDS, NTD, CMS, LEI, UEI,
   QID…) as `(scheme, value)` sets; **ORI validated by `^[A-Z0-9]{9}$`** (never by positional state
   assumption) with the `ucr_state_code ↔ usps_state_code` table; civil-ORI flag; Wikidata used but not depended on for US LE — SIG-IDENT-001/002/003/007.
2. **`normalize_org_name()`**: pure, deterministic, versioned, with a committed test-vector suite in CI;
   Sheriff's Office/Department collapse to one suffix; acronyms resolve by **exact lookup only**, never fuzzy-matched — SIG-IDENT-022.
3. **Deterministic cascade tiers 0–3** (exact canonical id / upstream crosswalk / normalized-name+state+class
   with a data-generated collision list / government-domain or address-key K1), all **auto-write**; slug parsing as a hypothesis generator via a versioned grammar; address keys K1–K4 with K3/K4 blocking-only — SIG-IDENT-020/013/015.
4. **Public identifier minting**: `sig:<type>:<uuidv7>`, dereferenceable with content negotiation; **stable
   across cluster splits/merges** via dated merge/split events with `redirects_to`/`split_into` and tombstones — SIG-IDENT-031/032.
5. **Crosswalk exports**: SIG↔external identifier crosswalk and the public `ORI9 → Census GEOID` crosswalk, subject to the licence gate — SIG-IDENT-033/034.
