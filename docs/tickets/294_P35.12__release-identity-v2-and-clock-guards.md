1. **`sig.publication-descriptor/2`** — the schema + writer + validator carrying §3.2's fields (the ★-marked v2 additions included): label, environment, spine snapshot block, `export.id`, code block (`commit`, `tree` state), `ontology_version`, gates block, evaluation, disclosures, `transparency_root`, `boundaries_root` (named as a JUR-01 input — row 297 supplies the value; the field exists now).

3. **Export id `sig-export-<ts>-<key8>`** — timestamp + 8-char key; the NEW-1 collision ends (two exports same-day differ).
4. **BuildSpec belief instant** — `export.sh` passes the `--as-of`/belief instant through into the descriptor's snapshot block.
5. **§3.3 clock guards** — T0 read once at run start; AR-3 freeze refusal unless `--emergency`; host-clock sanity check (a wildly wrong clock fails the run); `as-of ≤ built_at` enforced; no emitted date later than `built_at`; `--replay` → Class S; label derived from the run's instant, never from a stale record.

7. **Promotion refusals (SIG-REL-002)** — the promote path refuses: a v1 descriptor, a dirty tree, an unpushed commit, label `0.0.0`, a non-sha commit reference, a date earlier than the previous release.
8. **`p-17b713` exclusion** — the fixture candidate is excluded by the v2-only promotion rule.
9. Tests under `tests/`: same-day label allocation, export-id uniqueness, every clock guard (future as-of fails — the catalog AC), every promotion refusal, v1-descriptor rejection.
10. Requirement stamps in the PR body: `SIG-REL-001`, `SIG-REL-002`, `SIG-REL-003`.
