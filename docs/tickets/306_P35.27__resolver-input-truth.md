## Goal

Make the resolver's inputs truthful so its contradictions mean something. CP-9's change: (a) **valid time read** — the resolver evaluates claims *as of* their valid time: two claims asserting different values at different times are not a contradiction (a 2019 claim and a 2024 claim may both be true); only claims asserting different values for overlapping valid time are candidate contradictions; (b) **connector directness** — a claim's evidentiary weight reflects how directly its connector observed the fact (first-party observation vs republished registry vs derived claim — the declared independence/lineage P35.25 landed is what directness reads); (c) **tolerance-aware dissent** — a disagreement inside the predicate's declared tolerance is `contested`-at-most (a flagged dissent, disclosed), not a contradiction; outside tolerance it is a real conflict; the resolver's dissent output distinguishes them; (d) the **four-state contradiction vocabulary is preserved and honoured**: `uncontested`, `insufficient`, `resolved_conflict`, `unresolved_conflict` (the existing `_contradiction_state()` semantics) — `contested` is a dissent signal feeding `insufficient`/`unresolved_conflict`, never a fifth state invented ad hoc; (e) the rematerialize recomputes resolved values + states under these inputs and the state-distribution deltas are explained, not just shifted.

## In scope (deliverables)

1. **Valid-time-aware candidate selection** — only claims whose valid times overlap are candidate contradictions; a temporal non-overlap resolves as succession/newer-wins per the predicate's rule, never a conflict.
2. **Directness weighting** — the resolver's claim weighting reads declared lineage/independence (a republished copy does not outweight a first-party observation; a mirror's agreement is one voice — consumes P35.25's fields).
3. **Tolerance-aware dissent** — within-tolerance disagreement emits the `contested` dissent signal (persisted, disclosed) without escalating to conflict; outside-tolerance disagreement is a real conflict; the predicate's declared tolerance is read, never guessed.
4. **Four-state vocabulary preserved** — `uncontested` / `insufficient` / `resolved_conflict` / `unresolved_conflict` exactly as `_contradiction_state()` defines; `contested` is a dissent signal feeding the states, not a state.
5. **The rematerialize leg** — recomputes resolved values + states under the truthful inputs; the pre/post state-distribution counts with every delta class explained (temporal-deconflicted, directness-reweighted, tolerance-de-escalated, …).
6. **The `/status/` API-basis notice** — the S6 A-20 disclosure leg when the legs land.
7. Tests under `tests/reconcile`: non-overlapping-valid-time claims never conflict; overlapping-time disagreeing claims do; a mirror's agreement counts once; within-tolerance dissent is `contested` not conflict; no declared tolerance → disagreement is candidate conflict (the recorded default); the state vocabulary is exactly the four states.
