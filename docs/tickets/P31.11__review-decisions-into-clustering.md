## Goal
An accepted camera-site proposal becomes a human same_as edge that the next camera-site run clusters. A rejected one
never clusters. A source that republishes its own layer under two targets is recognized by target-level lineage
evidence, while genuinely distinct same-source devices at one point still never merge.

## In scope — deliverables
1. **Human edges (ADR-R9-HUMANER).** The camera-site run reads `review_decision` for `er_match:camera_site*` items.
   `accept` → a human same_as edge (disposition `human_accept`, `decided_by` = curator). `reject` → a hard cannot-link.
   No decision (the schema has no "unsure" value; P31.10's "unsure" writes nothing) → stays proposed. The ADR also
   states whether camera-site clustering consumes P31.3's `er_match:identity_duplicate:*` decisions (ADR-110 left
   that to this ticket) or leaves them to identity triage. **Zero decisions** → the run is identical to a run
   without this wiring (test-pinned). Precedence: a human decision outranks any later auto decision on the same pair; a
   conflict between two humans → stays proposed and is routed back. Human edges still respect constraints (b)/(c). An
   accepted edge that would violate one is recorded and refused, never silently applied.
2. **Stability.** Re-clustering keeps public ids stable per SIG-IDENT-032, and each run records how many clusters
   changed because of human decisions. `camera_site_run.summary` counts human accepts, rejects and conflicts.
3. **Within-source duplicate targets.** Record target-level lineage: two targets of one source whose captured content
   digests are identical (or row-identical) are marked `duplicate_target_of`. The ER then treats their record pairs
   as the same record (one lineage), which is an exception to constraint (a) that exists **only** with that evidence.
   A test pins that distinct same-source devices at one point still never merge.
4. **Metric.** "N resolved sites" counts human accepts, and the population note says how many proposals still await review.
**Split seam** (if the working set overflows): (1)+(2)+(4) human edges, stability and metric | (3) the
duplicate-target lineage (with its ADR section).

5. **Hosted.** Run camera-sites as a Cloud Run job (SHA-tagged image deployed by pinned digest, `pin_image_digest`).
   Read the hosted camera-site decision count first (expected 0). With 0 decisions the result is identical to the
   last run apart from the duplicate-target change (measured). Re-run +0. No RETURN PASS is opened here: the re-run
   after real human decisions accrue belongs to the **Round-10** review campaign (recorded on D-P30.2b-1).
