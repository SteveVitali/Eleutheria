## Goal
Bring the two API-backed government-record sources live under the ADR-083 carve-out: `muckrock` (records-request listings) and `usaspending` (procurement sub-awards) — real fetch → OCFL capture → typed claims into the spine, idempotent, fail-loud on content drift.

## In scope — deliverables
1. `data/live_targets.toml` rows: `muckrock` (the `www.muckrock.com` API listing endpoint, `SIG_MUCKROCK_TOKEN` via env, HG-09) and `usaspending` (the `api.usaspending.gov` spending-by-award endpoint, keyless) — both on the ADR-083 allow-list.
2. Confirm the `records` and `procurement` connectors' parse/extract handle the **live** API response shape (content-drift `ContentDrift` on divergence, per P25.1); keep shadow replay diff=0 over the committed fixtures.
3. Per-source HG-03 flip (reviewer + date) once the rights review is confirmed; the real fetch (records: MuckRock listing under the token; procurement: USAspending sub-award query — the P07.3 query, now *through* the gate).
4. Report + fetch records (rate-limit/robots-decision evidence); advance `D-P21.3-*` for these sources.
