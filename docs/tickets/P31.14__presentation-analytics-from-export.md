## Goal
The spine export emits every presentation analytic the surfaces render, as a licence-clean, named-denominator
artifact family. In export mode the web getters read it and fail loud when it is missing. No DEMO constant can reach
a national build.

## In scope — deliverables
1. **Artifact family (ADR-R9-ANALYTICS).** A new export-emitted family (e.g. `web/analytics/<name>.json`, **not**
   the demo-guarded `web/presentation/`), each file with a schema id, `as_of`, a named denominator, and its source
   compartments. Definitions: density bins (grid and zoom, tier-0 points only, coordinate-reduced per §19.4); network
   centrality (the measure — e.g. degree over materialized edges — and the focus-entity rule); the watch's tracked
   decision point; per-surface provenance summaries; evidence tiers W1–W3 for "How we know this".
2. **Producers** in `exports` reading the materialized graph, deterministic for one snapshot. Each file lands in the
   compartment its inputs allow; a mixed-licence file is refused by `assert_separated`.
3. **Web.** Switch those getters to the fixtures|export fail-loud pattern the nine P27.1 surfaces use; delete the
   overlay's coverage of them; keep zero-JS on content pages.
4. **Tests:** producers are deterministic and licence-separated; a build with an analytics file removed exits 1;
   `publish` accepts `web/analytics/` and still refuses `web/presentation/`.
5. Local proof: a fixture export plus an export over a seeded real-PG spine renders every surface's analytics.

## Out of scope
