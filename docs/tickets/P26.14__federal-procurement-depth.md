## Goal
Municipal procurement is live (P26.10: +13k claims). Federal procurement is
the same signal at the highest tier — and unlike municipal portals, the
federal award system is one public API: **USAspending** (api.usaspending.gov,
no key, US Gov data). Surveillance-relevant awards: ALPR, drones/UAS,
cell-site simulators, acoustic gunshot, predictive analytics, camera systems
— across CBP, ICE, FBI, DHS, DEA, state/local pass-throughs. Plus SAM.gov
depth: the keyed path landed 7 claims on a bounded slice — widen its query
set across the same keyword space.

## In scope — deliverables
1. **USAspending source + connector.** A `usaspending` source row; the
   award-search endpoint (`/api/v2/search/spending_by_award/` or the
   transaction endpoint) swept over surveillance keywords + relevant
   awarding agencies; fixtures + tests; `procurement_notice` claims
   (award id, recipient, awarding agency, amount, period, description,
   matched keyword) with verbatim literals + locators.
2. **SAM.gov depth.** Widen the keyed sweep — the P26.4 bounded slice to
   the full keyword set; same header-transport rules (key never in a
   recorded URL).
3. **Bounded windows.** api.usaspending.gov is rate-limited — page-bounded
   sweeps, recorded back-off, honest rate-limit events (P26.11 lesson:
   refused requests count — never re-probe a 4xx/429).
4. **Hosted run.** `sig-ingest-usaspending` job + monthly scheduler;
   `sig-ingest-sam-gov` re-run with the widened query; run rows + fetch
   records; spine delta; idempotent re-run.
5. **Records.** live_runs/ + GCS run rows; rights packet (US Gov public
   records → CC0-equivalent basis); ladder re-measured.

## Out of scope
- Award *text* extraction (contract PDFs — a later depth ticket);
  sub-award/prime hierarchies beyond what the search endpoint returns;
  municipal portals (P26.10 + its deferrals stand).
