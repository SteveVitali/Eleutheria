## Goal

One counting definition, stated everywhere it is used: a **source is one registry row** (`sig.source-row/1` — a connector, tenant, endpoint, capture host or mirror is an attribute/target, never a source); one exporter function computes the **lifecycle partition** — every registry row assigned exactly one state by the published precedence list (`withdrawn` → `published` → `ingested_not_published` → `permitted_not_ingested` → `gated` → `refused`, first match wins, at the release's belief cut); **identifiers carrying data without a registry row are listed as anomalies and never counted** (`okc_council_statement`, `okc-contract-c241032`, `osm`, …); and the stale public numbers — "178 sources tracked", "Independent sources 218" — are replaced by counts that name their predicate (F-431).
