## Goal
Persist configured-access edges as entity-ref claims. Replay the affected sources on the hosted spine **from captured
evidence**, then materialize relationship edges and accountability links, with > 0 rows and a +0 re-run.

## In scope — deliverables
1. **Access edges as claims.** `configured_access_edge` records become entity-ref claims
   (`configured_sharing_partner`, with `access_kind` as a qualifier) through P31.5's org identity, instead of being
   dropped. Other non-claim kinds (`index_only`, `research_task`) keep their current handling. Register the predicate
   if needed (`make gen`).
2. **Hosted replay from evidence.** Measure first: which hosted sources carry partner records, how many
   captures/claims (read-only), and **whether their capture bytes exist on hosted**. P31.4's finding (ADR-111): before
   the 2026-09-25 job roll **no capture was persisted anywhere** (container disk); since that roll every
   `scheduled-ingest` job writes OCFL captures to the restricted bucket (`gs://…-sig-restricted/evidence/captures/`,
   gcsfuse `SIG_CAPTURE_DIR`), so only sources that have run since the roll have replayable bytes.
   `connectors/replay.py` is deliberately **non-asserting** (SIG-INGEST-017/018: `ctx.replay` is forced true). An
   *asserting* re-interpretation of stored captures is a new, named decision, recorded in a short ADR (or an
   ADR-R9-ENTITYREF addendum). It must be a new `ingest_run` flagged `is_replay` with the original capture lineage,
   and it must write only the new entity-ref claims (the text claims dedupe +0). Run it as a Cloud Run job on a
   **digest-pinned** image (`pin_image_digest` / `sig-ops roll-jobs`, never `:latest`; the `materialize.sh` job
   pattern). Where captures do not exist on hosted, the fallback is the
   next scheduled cadence run on the P31.4-rolled image (digest-pinned; it now persists captures and records
   per-execution runs + completions, ADR-109/111), **never** an ad-hoc re-fetch of quota-bound APIs (SAM.gov,
   OpenStates). Re-run +0.
3. **Materialize.** `materialize.sh --apply run edges` and `run accountability` → count > 0 with evidence claims.
   Re-run +0. Read-only counts: `object_entity IS NOT NULL`, edges by type, links by kind.
4. **Report.** Commit a measurement file (counts by source/predicate, edges, links, and examples with evidence ids) under
   `docs/build/reports/p31.6-hosted/`. D-P30.2-2 → DONE with evidence.
