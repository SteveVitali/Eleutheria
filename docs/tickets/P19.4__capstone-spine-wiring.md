## In scope — deliverables
1. **`PgClaimSink`** (`db/src/db/claim_sink.py`, exported for `connectors` via a small factory in `connectors/src/connectors/sinks.py` — `connectors` must not import `psycopg` directly if it does not already; check `connectors/pyproject.toml`): implements `ClaimSink.assert_claims` by inserting claims L0–L3 with psycopg, append-only, evidence refs resolved to `evidence_capture` rows, `recorded_at` set by the DB; idempotent on identical input (natural key or content digest — reuse the spine's uniqueness contract; document the choice). Selectable from the connector runner as `--sink pg --dsn …` (extend the existing runner/CLI; the full `run` CLI is P21.3's). Flip `tests/e2e` xfail **`LD-F06b`**.
2. **`PgReadStore`** (`api/src/api/store_pg.py`): all 16 `ReadStore` methods over PG using `AsOf` for as-of reads and RLS-respecting connections; `create_app(store)` unchanged; a `sig-api serve --dsn … [--as-of]` entry (or extend the existing serve entry) selects it. `contradictions/contradiction/coverage_for/tasks/task`: read from the `graph_annotations` tables **if** rows exist, else **compute-on-read** via the existing pure functions (`reconcile.resolve.RESOLVE`, `inference.coverage`, `tasks.lifecycle.TaskPool`) — this seam is what P21.2 later replaces; name it `_compute_on_read()` and document it in ADR-059. Flip xfail **`LD-F06`**.
3. **ER over PG (LD-F04):** `sig-resolution match --dsn … --jurisdiction <id>` reads org/entity candidates from PG and writes match proposals; `ReviewQueue` gains a PG backend writing append-only `review_decision` rows (additive sqitch change if no table exists) while the JSONL backend remains the default for existing tests; `sig-resolution review decide --dsn …`. Flip xfail **`LD-F04`**.
4. **`python -m reconcile resolve --dsn …`**: runs `RESOLVE` over the PG claims for a jurisdiction and prints the resolution envelope (contradictions visible) — the CLI anchor P21.4's `run_okc.sh` needs; no persistence here (P21.2).
5. **Tests:** `tests/db/test_claim_sink.py` (N>0 rows from the `atlas` fixture replay; second run 0 new rows; no UPDATE/DELETE in the module — grep test), `tests/api/test_store_pg.py` (every `/v1/*` route + `/id/{type}/{uuid}` against `PgReadStore` over the composed fixture DB; one as-of query returns the historical value), `tests/resolution/test_pg_backend.py`. `tests/e2e`: the three xfails above become passes.
