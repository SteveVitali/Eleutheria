## Notes
France/Belgium is the recommended first adapter because the Technopolice ecosystem has already,
independently, made SIG's architectural choices in a non-US jurisdiction — including the documented
OSM-vs-isolated-database debate (OL-5.2-02) and the ~12,000-camera activist-database import
(OL-5.2-03). The French evidence base **stress-tests** the model: authorization by prefectural order
and procurement by a national open-data dataset. If either fails to map onto `LegalInstrument` or
`Contract`, that is a §5.3 defect to be found **here**, not in production. The import study is a
precondition of contribution (SIG-CONTRIB-016) and pairs with P16.2's human-mediated posture — SIG
proposes nothing at scale before understanding how the existing import was consulted and received.
