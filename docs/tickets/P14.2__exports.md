# P14.2 — Bulk exports, licence computation, and Zenodo deposit

- **Sequence:** 34 of 46
- **Phase:** 14 — API and exports
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1

## Goal
Versioned bulk dataset publication that gets the licensing right: multi-format exports whose licence is
**computed** from constituent SPDX with a build failure on an incompatible mix, ODbL-derived assets
shipped as a **separate file** from CC-BY graph data, per-row rights provenance, the crosswalk export,
Zenodo deposit with concept + version DOIs, and egress-friendly distribution.

## In scope — deliverables
1. **Versioned bulk artifacts** to object storage with checksums and a manifest — Parquet, CSV, JSONL, GeoJSON, PMTiles, JSON-LD/RDF, and a SQLite/Datasette bundle — SIG-EXPORT-001; tabular as a Frictionless Data Package, evidence bundles as RO-Crate — SIG-EXPORT-002; reproducible from `(as_of pair + ruleset version + resolver version)` via the same code path the API uses — SIG-EXPORT-003.
2. **Computed export licence**: the bundle licence is computed from the SPDX expressions of its constituent rights records, and the build **fails** if a share-alike input appears in an export whose declared licence does not satisfy it — SIG-EXPORT-004 / SIG-LIC-010; silently-travelling share-alike obligations are detected and default to the stricter regime — SIG-LIC-009a.
3. **ODbL split + per-row rights**: OSM-derived physical assets ship as a **separate file** under ODbL-1.0, SIG-original graph data separately under CC-BY-4.0 — SIG-EXPORT-005; every export carries per-row rights provenance and passes downstream the received attribution/provenance obligations per row — SIG-EXPORT-006 / SIG-LIC-011.
4. **The crosswalk export** (SIG-IDENT-033) published under the most permissive licence its constituents allow, prominently and separately from the main dataset — SIG-EXPORT-007.
5. **Zenodo deposit** each quarterly release: a **concept DOI** for the dataset and a **version DOI** for the release; evidence bytes excluded by size but the manifest of digests deposited — SIG-EXPORT-002.
6. **Egress-friendly distribution**: zero-or-low-egress object storage for bulk (S3-style evidence + CDN/mirror per §38.5) — SIG-EXPORT-008; torrent/IPFS SHOULD for the largest artifacts — SIG-EXPORT-009.

## Notes
The ODbL/CC-BY file separation (SIG-EXPORT-005) and the computed-licence build gate (SIG-EXPORT-004,
SIG-LIC-010) are the Part VIII licence-gate + ODbL-separation invariant realized at export time — a
single merged file would force the whole export share-alike, so keep them separate artifacts. Egress,
not storage or compute, is the existential cost (SIG-EXPORT-008): "success is the failure mode." This
ticket **owns** the export manifest/versioning contract that Phase 15 download surfaces reference.
