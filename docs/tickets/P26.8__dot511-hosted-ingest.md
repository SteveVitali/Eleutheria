## Goal
The 8 dot_511 sources (ky/il/ut/or/ia/wa/dc/mo) are permitted, connector-backed,
cadence-registered — but their `sig-ingest-dot-511-*` jobs were never deployed,
so 84k+ verified claims sit outside the hosted spine. Deploy and run them.

## In scope — deliverables
1. **Deploy the jobs.** `ops/gcp/scheduled-ops.sh --apply` (or the equivalent
   per-job upserts) creates the 8 `sig-ingest-dot-511-*` Cloud Run jobs + their
   `sig-sched-dot-511-*` monthly triggers — same env/secret pattern as the
   existing jobs (no new secrets needed — ArcGIS endpoints are keyless).
   If the image lacks the dot_511 connector, rebuild + push linux/amd64 first.
2. **Run each job for real.** `gcloud run jobs execute` per source; each run row
   lands in `gs://…-sig-restricted/ops/runs/dot_511_*/`; committed fetch records
   in `docs/build/reports/live_runs/`. Per-state claim counts recorded.
3. **Verify in the spine.** Via the cloud-sql-proxy (or a verification job):
   hosted claim count before/after, per-source counts, spot-check that
   camera-location claims carry real locators. Idempotent re-run proven on ≥1
   state (0 new claims on second run).
4. **Close the deferral.** `D-SOURCES.7-3` → DONE with the real hosted counts;
   the run ledger records job names, exec ids, and the spine delta.
5. **Keep the other deferrals honest.** `D-SOURCES.7-1` (5 gated states, HG-03)
   and `D-SOURCES.7-2` (keyed 511 APIs, HG-09) stay OPEN — named operator
   blockers, not engineering gaps.

## Out of scope

  operator's); the keyed Iteris/state APIs (credential work).
