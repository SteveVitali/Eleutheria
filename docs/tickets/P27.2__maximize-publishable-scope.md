## Goal
Turn the ~256k UNDETERMINED claims (dominated by `procurement`, `dot_511`, `france_belgium_procurement`
— government / public-record data) into **publishable** rows by recording their real licences through
the normal rights pipeline: fail-closed gate satisfied by *evidence*, not bypassed. ODbL / share-alike
stay in their own compartments; genuinely-sensitive classes are surfaced for explicit sign-off.

## In scope — deliverables
1. **Per-connector rights review** for each UNDETERMINED bucket the P27.1 audit named. For each: the
   evidenced licence basis (public-record / factual-compilation / CC0 / operator-terms / OGL / ODbL /
   share-alike), reviewer + date, terms URL + capture. Record as new `rights_record` rows + source
   registry links **through the pipeline** (append-only; new rows, never `UPDATE`).
2. **Compartment correctness.** New share-alike/ODbL sources declare their own compartment
   (`compartments.py`/`licenses.toml` data rows); the gate must still `assert_separated`. No permissive
   relicensing of share-alike — ship it correctly, not merged.
3. **Part VIII triage.** Explicitly hold `facial_recognition_world_map`, `pathways_rtcc_federation`,
   `pathways_acoustic_drone_location`, and anything touching person/officer naming for **operator
   sign-off** (HG-02/§43.4). Never auto-publish them; record the pending decision.
4. **Re-measure.** After the flips land, re-run the P27.1 audit → the new publishable fraction; target
   is ~100% of the non-sensitive bulk publishable, with the residue named.
5. **Records + gate:** `docs/build/runs/P27.2.md`, PR body, the reviewer-prepared flip list for the
   operator; **RETURN PASS** row for anything left HG-gated; `DEFERRALS` note (coordinated pass).
