## Goal

One export artifact holds, for every dossier, exactly which sources contributed what: **`claim_sightings`** — a new `EXPORT_QUERIES` read over publishable claims through an explicit-column view granted to `sig_export` only (K5 §3.1, J3 T-2) — accumulates per `(dossier key, source, predicate, run or month)` into **`sig.dossier-sources/1`**, one `web/dossier_sources/<slug-path>.json` per dossier plus a release copy and a gzipped `.runs.jsonl.gz` per (source, run) at country/admin-1 (monthly `series` at county/place), carrying the dossier-scope **`provenance_summary`** (SIG-UI-044 — the absorbed PKG-10 per-dossier "How we know this", D-K5-4 = yes) and a **`figures[]`** block whose every `by_source` sums to its `value` under a named `sum_rule`. The **same (dossier, source) rows** feed the source-side `contributions[]` on J3's `sources/<id>.json` — the TRANSP-008/040 shared-artifact rule: a dossier links back to its sources with the same numbers. Sources whose re-sighting links are absent emit `sightings: "run_level_only"` with only first-seen shown — never a silent zero (K5-P4, §3.3).

## In scope (deliverables)

1. **The `claim_sightings` view + `EXPORT_QUERIES` key** — explicit-column, `sig_export`-granted, publishable-claim-gated.
2. **The accumulation** — per (dossier key, source): records, located records, claims, claims by predicate, subjects by entity type and technology, placement basis and check counts, first/last seen and runs; per (dossier key, source, run-or-month): first-seen and re-sighted claims and first-seen records; per-dossier totals as the sums. Roll-up: a record counts in every ancestor of its placement chain (place → county → admin-1 → country, K4 §5.3). Contradiction records place through their subject; coordinate conflicts count per source.
3. **`sig.dossier-sources/1` emission** — the full §3.2 contract: release block, jurisdiction block with `chain` and `boundary_vintage`, named `definitions`, `totals`, `provenance_summary` (SIG-UI-044 fields verbatim incl. `human_review_status: "unreviewed"` and `not_evaluable` reasons, never omissions), `figures[]` (the K6 `fig-*` ids where the page carries them), `sources[]`, `cross_source` with honest `not_evaluable` (until DSRC-04), `placement.by_basis`, `runs_file`, `downloads`.
4. **The runs files** — `.runs.jsonl.gz` per (source, run) at country and admin-1; county/place carry monthly `series` and link the source's run log.
5. **The `run_level_only` fallback (§3.3)** — a source whose claims have exactly one capture link each across >1 completed run emits `sightings: "run_level_only"`, `last_seen: {not_recorded}`, `not_reasserted_in_latest_complete_run: {not_evaluable}`, first-seen only — with the reason printed. Recorded note: `D-P30.2a-2` (re-sighting links) is DONE since P31.7, so post-fix sources have real re-sightings; the fallback still applies per-source wherever the hosted links predate that fix — the check is per-source, not global.
6. **Source-side `contributions[]`** — J3's `sources/<id>.json` gains the per-dossier contribution rows from the same accumulation (one shared artifact).
7. **The tested invariants** — Σ `sources[].records` = `totals.records`; Σ `sources[].claims` = `totals.claims`; every `figures[].by_source` sums to `value` under its `sum_rule`; the same (dossier, source) numbers appear in `contributions[]`; export-time growth measured (J3 budget: +≤5 min — measured, recorded, not silently absorbed).
8. Tests: fixture spine → a dossier's `sig.dossier-sources/1` with the expected per-source numbers; a no-resightings fixture emits `run_level_only` with its reason; a multi-source record (fixture) flips `sum_rule` to `distinct` with disclosure.
9. Requirement stamps in the PR body: SIG-TRANSP-008 + SIG-TRANSP-040 (`Also:`) + the cited ids.
