## Goal

Make **every public route carry a declared page type** and make CI prove the type's rules: `web/src/lib/page-types.ts` maps every route pattern to its type — **T0 record & print** (`/r/**`, every `…/print/`, `/dispute/`, `/intake/**`, API `format=html` pages, tombstones, `/releases/<pub>/data/**`), **T1 content** (`/`, `/dossier/**`, `/entity/**`, `/sources/**`, `/data-freshness/**`, `/research-queue/**`, `/task/**`, `/watch/**`, `/evidence/**`, `/research-dossier/**`, `/releases/`, `/data/**`, `/status/**`, the K14 pages, and the same under `/s/<pub>/` and `/v/<pub>/`), **T2 explore** (`/map/`, `/explore/` — `/network/` becomes a redirect or a T1 page, `/search/`, the same under `/s/<pub>/`), **T3 tools** (`/curate/**`, ADR-068, never published) — each entry carrying its page type, owner ticket, data-contract id and no-JS equivalent (draft UXR-02's registry fields); an `astro:build:done` hook walks `dist/**/*.html` and **fails the build on any unclassified route** (K0 NEW-4, SIG-UI-041's amendment); `script-policy.spec.ts` replaces `islands.spec.ts` — T0 ships zero `<script` elements, T1 allows only `type="module"` scripts whose `src` is an allow-listed entry plus hashed Astro bootstrap (`application/ld+json` data blocks only where J3's D-J3-7 chooses — that answer is *linked files only*, recorded at row 318), every type forbids `on*=` attributes and `javascript:` URLs; `nojs-parity.spec.ts` proves T1's `main` text with JS off equals the text with JS on minus `[data-enhancement]`, and that T2's named no-JS equivalents exist and resolve; every e2e and axe sweep iterates the **discovered** routes, never a hand list. The AGENTS.md gotcha-6 and web/AGENTS.md gotcha-1 stanzas are rewritten to the landed registry (the "until P35.50/P35.51 land" hedge retires).
