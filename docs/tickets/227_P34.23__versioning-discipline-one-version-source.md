## In scope — deliverables

1. **One version source (G3 §9.3):** every Python package's `__version__ = importlib.metadata.version("<pkg>")`; a `make check` test asserts each `pyproject` version = its `__version__` = `web/package.json`'s version, and that none is `0.0.0`. *(SIG-REL-014)*
2. **Bump script:** `scripts/bump_version.py <x.y.z>` bumps all 14 packages and the web package together (dry run by default; used in the stack PR that precedes an operator tag); a test runs it on a temp copy. *(SIG-REL-014)*
3. **`resolver_version`** = the `resolution` package version + `+g<commit8>`, never the exports placeholder (G3 §3.2 ★; the 09-27 manifest reads `0.0.0`). *(SIG-REL-014)*
4. **CHANGELOG discipline (G3 §9.4):** `## [Unreleased]` split into Keep-a-Changelog sections, each entry naming its ticket and requirement ids; a CI check in the `docs` job fails a PR that touches `web/src/pages/**`, `web/src/layouts/**`, `api/src/api/{routes,app,models}.py`, `exports/src/exports/{release*,spine_export,manifest}.py`, `ops/public_routes.toml`, `ops/disclosures.toml`, `policy/**` or `ontology/src/**` without changing `CHANGELOG.md`, unless a commit carries a `Changelog: none (<reason>)` trailer. *(SIG-REL-014)*
5. **Tag procedure + template:** a short procedure (annotated tag `git tag -a v0.N.0 <sha> -m "<CHANGELOG section>"`, the operator's action; the tag object carries the true date, so no typed date) and `docs/build/reports/releases/TAG_TEMPLATE.md` (tree hash, green CI run ids, included PRs, production release labels from the range) that agents fill in the last stack PR of a range.
