## Goal
Ingest the Flock **portal** layer from the aggregator's public **CC BY-SA 4.0** API into a **separate
CC BY-SA compartment** (an export merging it with the CC-BY graph must fail the build), with no
challenge-defeating code, change detection keyed on the upstream snapshot field, historical back-fill
from archived captures, `ai_training_permitted = false` enforced, and the SIG-INGEST-031 fallbacks.
The `audit_structural` connector (audit CSVs) is the sibling ticket **P11.2**.

## In scope — deliverables
1. **`flock_portal` connector** sourcing the portal layer from the aggregator's public CC BY-SA 4.0 API, never from the vendor (whose every path returns a bot challenge); output lands in the **CC BY-SA 4.0 compartment**, never merged into the CC-BY graph — SIG-INGEST-035, SIG-LIC-004a.
2. **No challenge-defeating code** anywhere; the connector honours a challenge/bot-management response as a **refusal** (crawler-conduct rule 4) — SIG-INGEST-036/037, SIG-INGEST-031 (challenge-defeating crawler explicitly excluded).
3. **Change detection keyed on the upstream `data_last_updated` / snapshot field**, not on fetch time; SIG does not poll faster than the upstream refreshes — SIG-INGEST-030c.
4. **Historical back-fill from archived captures** of the API endpoint (the aggregator's archived responses are the only longitudinal record, since vendor domains are unarchivable) — SIG-INGEST-030b.
5. **`ai_training_permitted = false`** recorded and enforced for this source — SIG-LIC-004b.
6. **Portal-existence events**: portal disappearance produces an event and a task; portal appeared / no known deployment handled — SIG-INGEST-035 (`portal_exists` / disappearance), feeding the §17.6 artifact event.
7. **Snapshot diffing** at the extracted-field level producing **per-field change events** with both values and both dates — via P08.2's §29.7 reconciler (SIG-RECON-045, owned there).
8. **Portal sharing sections** land as **configured access only, directional, with blank cells as negatives**, single-snapshot edges carrying `valid_from_kind='unknown'`; asymmetry/finding emission runs **through P08.2's §29.3 reconciler (owned there)** — this ticket produces the raw edges/captures and invokes that logic — SIG-ONTO-042/044.
9. **The SIG-INGEST-031 fallbacks** implemented and retained: (a) records acquisition of the underlying configuration; (b) contributor-submitted human captures; (c) partner archives — because the API is a single dependency — SIG-INGEST-031.
