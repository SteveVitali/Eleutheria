## Goal

Give every claim a declared lineage and namespace so independence is a property of the data, not an inference. CP-4's change: (a) **lineage fields** — sources and claims carry declared `origin` / `mirror_of` / `derived_from` relations: a source that mirrors another says so, a claim derived from other claims says which (SIG-EPIS-009's `derived_from_claim_ids` — persisted, not recomputed); (b) **`id_namespace`** — every claim's subject identifier carries its namespace so two sources' coincidentally-equal local ids never read as the same subject without a declared crosswalk (the SIG-CONF-014 independence guarantee: independent corroboration counts only across genuinely independent namespaces/lineages); (c) **independence classes** — each source/claim declares its independence class (primary, mirror, derived, syndicated, …) so corroboration-weighting reads the declaration, never guesses it; (d) the registry carries the lineage declarations for existing sources and a rematerialize back-populates the spine — undeclared is a first-class explicit value, never an absent field presented as independent (SIG-EPIS-029's overlapping-layers rule: undeclared overlap is disclosed, not silently merged). The catalog's owner requirement is **SIG-CONF-014** — the only row in this family with a §56 `Owner:` line.

## In scope (deliverables)

1. **Registry lineage declarations** — `origin` / `mirror_of` / `derived_from` / `independence_class` fields on `sources.toml` rows; the known mirror/derived relations declared (per CP-4's mapping — e.g. republished-registry sources mirror their original; syndicated datasets name their upstream); `undeclared` is the honest default, never `independent`.
2. **`id_namespace` on claim subjects** — schema + emit: every claim's subject identifier carries its namespace; the namespace vocabulary is declared (per-source local, scheme-qualified canonical, …).
3. **`derived_from_claim_ids` persisted** — derived claims store the claim ids they derive from at emit time (SIG-EPIS-009); the field is populated for new derived claims and back-populated where the derivation is recoverable, `undeclared` where it is not.
4. **Independence-aware corroboration** — the reconcile/confidence path reads `independence_class`: corroboration counts across declared-independent lineages only; a mirror's agreement with its original is one voice, disclosed as such.
5. **The rematerialize leg** — back-populates the fields on existing rows; bounded, dry-runnable, resumable, idempotent; its completeness counts are the recorded evidence.
6. **The `/status/` API-basis notice** — the S6 A-20 disclosure leg when the legs land.
7. Tests under `tests/` (db + reconcile + inference): a mirror never corroborates its original as independent; an `undeclared` class weights as unclassified, never independent; a derived claim persists its `derived_from_claim_ids`; coincidentally-equal ids in different namespaces never merge; a registry row without declarations parses and loads (additive fields only).
8. Requirement stamps in the PR body: SIG-CONF-014 + the cited ids.
