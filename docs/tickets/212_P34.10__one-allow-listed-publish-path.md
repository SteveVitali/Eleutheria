## In scope — deliverables

1. **Don't emit internal routes:** public builds skip `web/src/pages/curate/**` unless `SIG_BUILD_INTERNAL=1` (set by the web e2e suite), or the curation shell builds to its own output.
2. **Allow-list:** a committed `ops/public_routes.toml` of every approved top-level route and file, carrying `/data-collection/` (P35.38a, S6c); the withdrawn surfaces stay off it (C-12, **"Accept the list (Recommended)"**, 2026-10-01T05:03:05Z: `/curate/`, `/intake/`, `/contribution-back/`, the `/task/new/` demo pages) and so do `/visual-language/` and the handle-bearing pages (A-0.3 = b; removed by republish #1). The publish exits non-zero when the build holds an unlisted top-level entry.
3. **Content assertions:** refuse HTML with `data-testid="curate-auth-banner"`, a form action to `127.0.0.1` or `localhost`, or a demo-fixture marker (`demo_` task slugs).
4. **Release record:** `dist/.sig-release.json` (release id, git commit, build time, tree digest; image digests where relevant) written by the publish (SIG-OPS-004).
5. **One command:** `sig-ops publish-web` (dry-run by default; `--apply` to sync): prepare → allow-list and content assertions → release record → one sync → post-sync verify. The sync never deletes `r/`, `releases/<pub>/`, `entity/`, `conf/`; exactly one generator owns `/releases/index.html`; a staged release tree is published by the same command. The runbooks get an appended note forbidding hand-typed syncs to public buckets.
6. **Absence probes:** `http-absent` targets in `ops/cadence.toml` (`/curate/`, `/curate/submit/`, one demo page, `/releases/`, `/research-dossier/`, `/intake/`) on every public origin; the publish verify step runs them at once; the 6-hourly probe picks them up at its next roll.
7. **Regression tests (G1 §3.2 item 6):** the sync refuses `curate/`, an unlisted top-level dir and a `demo_` page; every page built from an internal layout maps to a route off the list and every listed prefix exists; an export-mode build without `SIG_BUILD_INTERNAL` emits no `curate/`; every non-public route has an `http-absent` probe.
