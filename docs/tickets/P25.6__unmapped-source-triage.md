# P25.6 — Unmapped-source triage: dispose every registry row without a connector

- **Semantic id:** `LIVE-OPS.6` · **Phase:** 25 · **Kind:** ticket · **Tag:** p25-backlog
- **base_branch:** current checkout · **Depends on:** P25.1–P25.5 (the class connectors a promoted source would join)
- **Run:** `implement-spec spec=docs/tickets/P25.6__unmapped-source-triage.md live_verification=false`
- **Gate status:** none for the triage itself; a *promotion* to a live connector carries that class's HG-03/04.
- **Live stage:** offline (triage/classification); promoted sources fetch under their class ticket.

## Goal
Give **every** one of the 98 registry rows with no connector (51 REFERENCE, 38 LINK, 9 MIRROR — `SOURCE_LIVE_OPS_MATRIX.md §B`) an explicit, recorded live-op disposition, so no source is left unscoped — the completeness guarantee for the whole source registry.

## In scope — deliverables
1. Classify **each** unmapped source into exactly one disposition, recorded on its registry row (a `live_disposition` note field or the review packet): **LINK-only** (cited, never ingested as a feed), **REFERENCE** (context/provenance, not a structured feed), **MIRROR** (archived copy — fetched from the archive, not origin, if ever), or **PROMOTE** (exposes a real API/feed → a genuine future live connector).
2. For each **PROMOTE**, file it into the right class ticket (P25.2–P25.5) or a new class connector, with an HG-03 flip prerequisite noted — never flipped here.
3. A **completeness check** (a `check_backlog`-style assertion or a test): `mapped ∪ LINK ∪ REFERENCE ∪ MIRROR ∪ promoted == 121` — every registry row has exactly one disposition; CI-enforced so a newly-added source must be dispositioned.
4. Update `SOURCE_LIVE_OPS_MATRIX.md` with the resolved per-source (or per-cohort) dispositions.

## Out of scope
- Implementing any promoted connector's live fetch (that is its class ticket). Flipping any source. Building connectors for LINK/REFERENCE/MIRROR rows (they are, by disposition, not live feeds).

## Acceptance criteria
- [ ] every one of the 98 unmapped sources carries exactly one recorded disposition *(deterministic — the completeness assertion passes)*
- [ ] each PROMOTE names its target class ticket + HG-03 prerequisite *(deterministic)*
- [ ] the completeness check is CI-enforced (a new undispositioned source fails it) *(deterministic)*
- [ ] `make check` green; `SOURCE_LIVE_OPS_MATRIX.md` current *(deterministic)*
