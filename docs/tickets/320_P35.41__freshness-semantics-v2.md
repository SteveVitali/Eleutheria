## Goal

Freshness that says only what it knows: **one shared verdict function** `freshness_verdict(cadence, executions, at)` used by the exporter, the status lane and the alerting path — evaluated at the release as-of on release pages and at status time on status pages, always shown with its evaluation time (SIG-TRANSP-029); **volatility** derived from the ontology predicate registry over **all** of a source's published claims (the dated-only vote bug dies) with staleness stating its evaluable/not-evaluable counts — never "unknown", never "0 stale" for an unevaluable source (SIG-TRANSP-030, F-137); **two change dates** — "last upstream change" from the upstream's declared last-modified where available else a canonical `records_digest` (a byte-only change never moves it), and "last change in SIG's records" shown separately (SIG-TRANSP-031); and **cadence** disclosed as declared (rule to day granularity, `one_time_load` first-class) / next scheduled day / observed (SIG-TRANSP-007) — with the two clocks separated: no reader-time-dependent value on a release page (TRANSP-034's `Also:`).
