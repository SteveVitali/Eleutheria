## Goal
Give every camera-registry predicate that lands on the hosted spine a row in the ontology's generated
predicate registry (volatility class + half-life, resolution strategy, and the genre × predicate
directness matrix), so §28 value resolution can adjudicate camera claims (e.g. conflicting coordinates
or operators reported for the same subject) instead of rejecting them as inadmissible.

## In scope — deliverables
1. **Measure first.** On the hosted spine (read-only, DB user `sig`), list every distinct predicate with its claim count and whether it has a registry row. Commit that inventory; it defines the exact set to register (expected: `camera_latitude`, `camera_longitude`, `camera_operator`, `camera_external_ref`, `camera_jurisdiction`, `camera_coordinate_source`, `external_id`, … — use the measured list, not this guess).
2. **Register them in the LinkML ontology** (never hand-edit `ontology/generated`). For each: volatility class + half-life, resolution strategy (coordinates need a spatial-tolerance strategy rather than exact-match; identifiers are identity-bearing; operator/jurisdiction are categorical), and directness per genre. Run `make gen`, commit the regenerated artifacts, `make verify-gen` clean.
3. **ADR (next free number, `## Revisit trigger`, homed under BL-057, Appendix F row + `BUILD.sh`)** recording the per-predicate choices and why.
4. **Hosted re-materialization:** rebuild the `sig-materialize` image from this branch (tagged; do not move `:latest`), run the resolution materializer in GCP via `ops/gcp/materialize.sh`, measure resolution envelopes written for camera predicates (resolved vs unresolved/contradiction), re-run for `+0`. Regenerate the scale section of `docs/build/reports/P28.1_resolution_eval.md` from a committed measurement file.
5. **State precisely what this does and does not change.** Value resolution adjudicates values within a subject; it does NOT merge duplicate cameras across sources (P30.2b). Record the correct meaning of the numbers so P30.3's public headline cannot misrepresent them.
