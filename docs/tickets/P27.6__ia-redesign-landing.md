# P27.6 — IA + navigation redesign + landing + design system (P27)

- **Semantic id:** `LAUNCH.6` · **Phase:** 27 · **Kind:** ticket · **Tag:** p27-launch
- **base_branch:** `devin/p27-5-web-data-layer-wiring` · **Depends on:** P27.5 (real data on every page), P27.4 (dossier index + manifest as_of)
- **Run:** `implement-spec spec=docs/tickets/P27.6__ia-redesign-landing.md`
- **Gate status:** engineering — `web/` redesign; **zero-JS content** (React may author static components via `@astrojs/react`; hydration is P27.9 only).

## Goal
The "full launch redesign": a coherent information architecture, an uncluttered grouped navigation, a
real national landing page, a per-jurisdiction dossier index, correct canonical/as-of metadata, and a
modern design system — a beautiful, convincing public surface that still renders zero-JS and passes
WCAG 2.2 AA.

## Load (cite; do not copy)
- `docs/2_canonical_design_spec.md` §15 (web shell), SIG-UI-035 (belief-pinned permalink/citation), SIG-UI-036/037 (static-first, zero-JS), SIG-UI-044 ("how we know this"), the SIG-UI-010..015 dossier surface.
- Code: `web/src/layouts/BaseLayout.astro` (the 13-link nav; the `sig.example` canonical fallback), `web/src/pages/index.astro`, `web/src/styles/epistemic.css`, `web/astro.config.mjs` (`site`), P27.4 manifest (`as_of`/ruleset), the P27.5 data layer.

## In scope — deliverables
1. **Navigation + IA.** Replace the flat 13-link nav with a grouped structure (primary product ·
   secondary/about · reference), collapsible/uncluttered, keyboard-accessible. Fix the **hardcoded
   `/dossier/oklahoma-city/`** link to the dossier index. Reconcile the **`map`↔`reference-map`** and
   **`network`↔`reference-graph`** duplication (one canonical surface each; the "reference" pages either
   fold into the visual-language doc or are removed).
2. **National landing page.** Rebuild `index.astro` as a real overview of the national dataset: honest
   headline counts (with named denominators, no total), the jurisdiction reach, entry points to
   map/network/dossiers/watch, and the epistemic framing ("absence is not evidence of absence").
3. **Per-jurisdiction dossier index.** A browsable index of all publishable jurisdictions (from the
   P27.4 dossier index), each linking to its dossier — the "local dossier" made discoverable at scale.
4. **Real metadata.** Set `astro.config.mjs` `site` to the real public origin; wire the belief-pinned
   permalink + `as_of`/ruleset from the **export manifest**, not the frozen `fixtures.ts` constant.
5. **Design system.** A cohesive modern visual system (typography, spacing, color, the epistemic
   glyphs/tokens) applied site-wide; optionally author reusable components via `@astrojs/react`
   rendered to **static HTML** (no client JS on content pages).
6. **Records:** `docs/build/runs/P27.6.md`, PR body; ADR for the IA change if it supersedes a landed
   SIG-UI decision (SIG-ENG-003).

## Out of scope
- Interactive islands / client JS (P27.9); empty-state + large-table polish details (P27.7); deploy
  (P27.8); changing data shapes (P27.4/P27.5).

Cited from `docs/tickets/00_MANIFEST.md § Cross-cutting invariants`: zero-JS + WCAG 2.2 AA on public
