## Goal
The write-once evidence layer under every claim: an OCFL 1.1 store on object storage with multihash
content addressing, the capture-and-extraction pipeline (WACZ for JS apps), the three storage tiers, and
the sealed-capture metadata-only public representation.

## In scope — deliverables
1. **OCFL 1.1 store** on S3-compatible object storage — one object per source stream, one version per
   capture, `sha512` in the manifest, BLAKE3 in the `fixity` block; **readable without SIG's code** — SIG-EVID-005.
2. **Content addressing** as **multihash** (base32-lowercase), interop digest SHA-256/512, dedup by digest,
   `(content_digest, source_uri)` unique — SIG-EVID-002/003/004.
3. **Object Lock in governance mode** (never compliance mode) with a documented default retention, versioning enabled — SIG-EVID-006.
4. **Capture pipeline**: WACZ 1.1.1 for JS-rendered artifacts, with the full capture set (WACZ + screenshot
   + extracted payload + raw HTML) sharing one `evidence_artifact` — SIG-EVID-007/008.
5. **Storage tiers** `public`/`restricted`/`sealed`, redaction as a **new capture** with `parent_capture_id`,
   access logging with its own retention — SIG-EVID-009/011/012.
6. **Sealed captures expose a metadata-only public representation** (existence, source, date, digest, claims supported) — SIG-EVID-010.
7. **Disappearance/link-rot** handling: disappearance events, no deletion, research-task generation, Wayback
   sweep — SIG-EVID-013/014/015. `ingest_run` recording for reproducibility — SIG-EVID-016/017.
