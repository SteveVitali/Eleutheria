# P26.9 — Camera-registry expansion: municipal, transit, national (P26)

- **Live stage:** real fetches into the hosted spine; outcomes recorded.

## Goal
dot_511 covers *state* DOT feeds. The same operator-published-registry class
exists at other tiers: **municipal/city** traffic-camera programs (NYC DOT,
Chicago CDOT, Seattle SDOT, LA, Atlanta, Denver, …), **transit agencies**
(bus/rail camera inventories many publish under open-data portals), and
**non-US national/state registries** (UK, Canada, Australia camera layers).
Extend the physical-layer registry coverage the same way — registries only,
never feed content.

## In scope — deliverables
1. **Enumeration.** Authoritative discovery per tier: city open-data portals
   (Socrata/ArcGIS hub camera layers — many cities publish traffic-cam layers
   under `data.<city>.gov`), transit-agency open data, and non-US registries
   (e.g. UK National Highways/TfL feeds, Canadian provincial/municipal 511s,
   Australian state feeds). Record the enumeration source per host; targets as
   data (`dot_511_targets.toml` extended, or a sibling registry TOML).
2. **Claims.** The `dot_511` connector path reused where the endpoint shape
   fits (ArcGIS REST / documented JSON); a thin per-platform adapter where it
   doesn't. Camera-location claims with evidence+locators; C1 sensitivity +
   `apply_tier` per coordinate as before; media-field blocklist unchanged —
   feed content is never fetched.
3. **Rights + robots.** GL-GATE-06 flips for resolved-clear terms with packets;
   unresolved terms stay gated naming the blocker; every host's robots
   recorded (4xx = no policy per ADR-087; `Disallow` honored).
4. **Hosted ingest.** New cadence rows + `sig-ingest-*` jobs deployed and run
   into the hosted spine (the P26.8 machinery); per-source counts recorded;
   idempotent re-run proven on ≥1.
5. **Records.** `live_runs/` + GCS run rows; the ladder re-measured; any
   gated/keyed sources become DEFERRALS rows naming their blocker.

## Out of scope
- Feed/video content (Part VIII — registries only); private/commercial camera
  networks (own rights review); the 5 gated dot_511 states + keyed APIs
  (`D-SOURCES.7-1/7-2` — operator blockers); non-camera source classes.
