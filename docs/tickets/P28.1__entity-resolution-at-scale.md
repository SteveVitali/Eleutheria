## Goal
Dedup the ~75k+ geolocated observations (dot_511/osm/atlas/flock overlap) + orgs into **resolved
entities materialised in the spine** with visible provenance, governed by a **measured** precision
floor — activating the built-but-dormant ER + gold-set + quality-gate machinery on the real spine.

## In scope — deliverables
1. **Run ER over the real spine** (deterministic cascade 0–3 + Splink 4–5) and **materialise `resolution`
   envelopes** — a NEW sqitch change (deploy/revert/verify), append-only (a resolution is a stored
   decision, ADR-005; never a recompute-in-place). Idempotent re-run.
2. **Bootstrap the gold set (agent-created seed):** an **agent/maintainer-labelled stratified seed**
   (oversample the ambiguous weight bands) as one adjudicator + an **LLM adjudicator**
   (`adjudicator="llm:<model>@<version>"`, reading the versioned `adjudication_rules`, rationale in
   `note`) as the second; disagreement → disputed (never a silent pick).
3. **Calibrate:** compute LLM-vs-seed **Cohen's κ** (`GoldSet.kappa`); trust LLM gold only if **κ ≥ 0.7**
   (tune + record); else the LLM is a suggester and pairs route to review. The **frozen holdout is
   agent/maintainer-verified** (never LLM-only — precision is measured against it).
4. **Run the quality gates:** pairwise P/R/F1 at tier boundaries + B-cubed on the holdout +
   `demote_auto_write_tiers` (set `auto_write_precision_threshold ≥ 0.98`, tune against measured holdout
   precision) + `cluster_shape_alerts`. Any auto-write tier below floor → demoted to review.
5. **Review + active learning:** tiers 4–5 + disputed clusters → `review_pg`/`review_queue`; route
   model↔LLM disagreements + near-boundary pairs to review first (maximise label value).
6. **Eval report** (holdout P/R/F1, κ, dedup ratio, resolved-site count, demotions, cluster-shape
   alerts) → `docs/build/reports/` + surfaced on the methodology/coverage page (SIG measuring its own
   method, §32/SIG-METRIC-008b).
7. **ADR-R6-RESOLVE** (materialise at scale; the eval methodology; the LLM adjudicator; lean-auto with
   the measured floor). **Open D-R6.1-EVAL** (revisit auto-vs-human from first principles once real
   ground truth exists — the LLM-bootstrap + first-pass floor are provisional; asymmetric false-merge
   loss noted).

## Out of scope
- The relationship network (P28.2), contradictions (P28.3), coverage (P28.4), surface refresh (P28.5);
  any `UPDATE`/`DELETE` of claims; publishing a total; auto-merging below the measured floor.

## Acceptance criteria
- [ ] ER runs over the real spine and materialises `resolution` envelopes (new sqitch change; append-only; idempotent re-run +0) *(deterministic + live-gated)*
- [ ] the gold set is built (agent seed + LLM adjudicator), LLM-vs-seed κ recorded, holdout human-verified + frozen (relabel refused) *(deterministic)*
- [ ] quality gates run on the holdout: P/R/F1 + B-cubed + auto-write demotion at the measured floor + cluster-shape alerts; the eval report is committed *(deterministic)*
- [ ] tiers 4–5 + disputed + active-learning-selected pairs land in the review queue; no auto-merge below floor *(deterministic)*
- [ ] `make check` + `make test-db` + build-memory green; ADR-R6-RESOLVE written; D-R6.1-EVAL opened *(deterministic)*

## Cross-cutting invariants
Cited from `docs/tickets/00_MANIFEST.md § Cross-cutting invariants`: append-only (resolution = new stored
decision rows); every inference labelled; contradictions stay visible; coordinate reduction (§19.4); never
a total (§32); Part VIII; no fabricated green (a provisional-eval basis is disclosed, not hidden).

## Notes
The eval is a **process**, not a one-time gate (design §2.5): re-measure each run, grow the gold set from
review/correction/dispute decisions, re-freeze holdout versions, track κ over model drift. D-R6.1-EVAL is
gate-relevant — a public "resolved sites" claim discloses the provisional-eval basis until it closes.
