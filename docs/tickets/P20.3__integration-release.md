## In scope — deliverables
1. **`docs/build/tools/merge_dryrun.sh`** (committed, idempotent, read-only w.r.t. refs): `gh pr list --state open --json number,headRefName,baseRefName` → for each PR in number order, in a throwaway `git worktree add --detach /tmp/sig-merge origin/main`: `git merge --no-commit --no-ff <head>`; record `rc` + conflicted files; `git merge --abort`; then a second pass that accumulates bottom-up on the detached HEAD (never a branch ref) and asserts the final tree equals the top PR's tree; `git worktree remove --force`; prints a table and exits non-zero on any conflict. The operator runs this **right before merging** (when PRs #55–#63 also exist); the ticket runs it now over #20–#53 and pastes the table.
