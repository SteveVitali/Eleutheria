# P27.4 — Spine-backed national export bundle (P27)

- **Semantic id:** `LAUNCH.4` · **Phase:** 27 · **Kind:** ticket · **Tag:** p27-launch
- **base_branch:** `devin/p27-3-export-data-shaping` · **Depends on:** P27.3 (shaped reads), P27.1 (frozen contracts), P27.2 (publishable rights)
- **Run:** `implement-spec spec=docs/tickets/P27.4__spine-backed-export-bundle.md live_verification=true`
- **Gate status:** engineering — the export **reads** the spine and writes bundle files; the fail-closed licence/compartment gate is enforced, never relaxed.

## Goal
Make `sig-exports build` emit a real **national** export from the shaped spine (P27.3), replacing the
hardcoded okc/france fixture requests, and produce every artifact the public surfaces consume — to the
frozen P27.1 contracts — so the static site is the real graph "by construction" (§38.1).

- Code: `exports/src/exports/cli.py` (`build`, `_jurisdiction_request` — to replace), `exports/src/exports/web_dossier.py` (`build_web_dossiers` — to replace), `bundle.py`/`compartments.py`/`manifest.py`/`tiles.py`, the P27.3 shaped `PgReadStore` reads.
- P27.1 per-page contracts; `web/src/lib/*-fixture.ts` (target shapes).

## In scope — deliverables
1. **Real dossier bundle.** `build_web_dossiers` reads the spine: a **dossier index** (all publishable
   jurisdictions) + per-jurisdiction dossiers in the existing `Dossier` contract — no hardcoded
   okc/france. Fixtures stay as the CI/demo default; the real path is `--from-spine`/`--dsn`.
2. **Map layer.** National geolocated sites → GeoJSON + PMTiles (via `sig-exports tiles`), ODbL layer
   kept in its own compartment, coordinates tier-reduced (§19.4).
3. **Network layer.** Sharing-edge / vendor-relationship dataset for the graph surface.
4. **Feeds.** `data-freshness` (all publishable sources, §32.4 volatility classes), `coverage-metrics`
   (§32 named denominators, no total), `watch`, `evidence`, `corrections`, `research-queue` — each to
   its frozen contract, each licence-compartmented and gate-checked.
5. **Manifest + provenance.** The export manifest carries the real `as_of` / ruleset / per-compartment
   licences + PROV-O lineage; the site reads `as_of` from here (P27.6 wires it).
6. **Records:** `docs/build/runs/P27.4.md`, PR body; a live build over hosted producing `exports/out/*`
   for the national dataset; the bundle passes `assert_separated` + the fail-closed gate.

## Out of scope
- Web/page changes (P27.5); IA/design (P27.6); deploy/publish (P27.8); relaxing the licence gate or
  co-mingling compartments; recomputing shapes (that's P27.3 — this ticket serialises them).

## Acceptance criteria
- [ ] `sig-exports build --from-spine` emits the dossier index + per-jurisdiction dossiers from the real spine (no hardcoded okc/france) to the P27.1 contract *(deterministic + live-gated)*
- [ ] map (GeoJSON+PMTiles), network, freshness, coverage, watch, evidence, corrections, research-queue artifacts are emitted to their frozen contracts *(deterministic)*
- [ ] the fail-closed gate holds: ODbL/share-alike in separate compartments, `assert_separated` passes, an UNDETERMINED/ excluded source is dropped loudly, never co-mingled *(deterministic)*
- [ ] a live build over hosted produces the national `exports/out/*`; manifest carries real as_of/ruleset/licences + PROV-O *(live-gated)*
- [ ] fixtures remain the CI default (existing e2e unaffected); `make check` + `tests/exports` + build-memory green *(deterministic)*
