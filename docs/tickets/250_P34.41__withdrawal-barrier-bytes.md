## In scope — deliverables

1. **Tombstone body on every alias (C4 NEW-14; DR-C4-08 agent draft; G3 §8.3–8.4).** `apply_withdrawals` emits a `withdrawn_routes.conf` covering `/<route>/`, `/<route>/index.html`, the no-slash form and `.json`, and nginx serves 410 with the `sig.tombstone/1` body (`target_kind`, `target_id`, `withdrawn_at` from the clock, a public-safe `reason_class`, `disposition_ref`, `superseded_by`, the release label, and a link to the corrections page — never an embedded e-mail address).
2. **Entity stubs and page indexes.** Entity stubs are generated from the deny set; `page_index` pages that list a withdrawn record drop it or show the tombstone link.
3. **`/r/<pub>/` landing (C4 NEW-29).** A landing page (with meta description) replaces the 403.
4. **Tests.** A composed-stack or nginx-container test proves every alias of a withdrawn fixture route returns 410 with the tombstone; a unit test over `_route_targets` proves alias completeness from the deny set.
