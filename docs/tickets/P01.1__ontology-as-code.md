## Goal
One schema source of truth generating all downstream forms: a LinkML ontology for every §11 entity
and §12 edge, the §13 vocabularies as SKOS, the predicate registry, and generators for SQL DDL,
JSON Schema, OWL/SHACL, Pydantic, and docs — with the generalization conformance suite.

## Load
- `docs/2_canonical_design_spec.md` §8 (conceptual architecture), §11 (entity catalog), §12 (relationship catalog), §13 (controlled vocabularies), §20 (versioning).
- Part 0, Part I §3, Appendix E glossary.

## In scope — deliverables
1. **LinkML** ontology covering every §11 entity and §12 edge, incl. the `[NEW]` entities (Jurisdiction, Person, CandidateAsset, FundingInstrument, LegalInstrument, RecordsRequest) — SIG-ONTO-*.
2. §13 vocabularies as **SKOS**: technology `domain→family→technology`, capability `verb.object.scope`, evidence/epistemics, the four lifecycle tracks, org/evidence/acquisition/role enums, predicates — with i18n.
3. The **predicate registry** with a volatility, strategy, and directness row per predicate — SIG-ONTO-067.
4. Generators producing SQL DDL, JSON Schema, OWL/SHACL, **Pydantic**, and docs from the single source.
5. The **generalization conformance suite** (`tests/ontology/generalization/`) — SIG-CHART-028.

## Out of scope (do NOT do here)
- Physical DDL of the claim spine / append-only / resolution tables — P02.1 (consumes generated DDL).
- Populating any data or connectors.
