# P00.2 — Executable policy and the decision record

- **Sequence:** 2 of 46
- **Phase:** 0 — Foundations, governance, ecosystem coordination
- **base_branch:** current checkout — the branch the previous ticket left checked out (stacked PR chain); `main` for P00.1
- **Depends on (must land earlier in the stack):** P00.1 (uses the `policy/` package scaffold and CI)
- **Run:** `implement-spec spec=docs/tickets/P00.2__policy-as-code.md`

## Goal
Turn SIG's **executable** governing rules into a real, tested `policy/` package and write the
architecture decision record. Every rule that runs in the pipeline — the licence-compartment gate,
the coordinate matrix, the officer test, crawler conduct, threat-model coverage — becomes a pure,
versioned function with a test; every architectural choice becomes an ADR with a revisit trigger.

- `docs/2_canonical_design_spec.md` §26 (crawler conduct), §42 (licensing & rights), §43 (publication policy — coordinate matrix, officer test), §44 (threat model & security), §15.5 (the ADR set).
- Part 0, Part I §3, Appendix E glossary. Stack-ADR cross-refs: §17.3 (OCFL/S3), §38.5 (egress), §21.8 (Dagster), §47 (stack).

## In scope — deliverables
1. **`policy/` as a tested package** (SIG-ENG-014): each executable rule below is a pure, versioned function with a test — not a prose note.
2. **Crawler Conduct Policy** (§26) — the eight operative rules, `robots.txt`/content-signal honouring, no-circumvention as a legal posture — SIG-INGEST-036/037.
3. **Licensing decision** (§42): per-source rights-record shape, SPDX + `LicenseRef-SIG-*`, the **N-compartment export model keyed on rights** with a per-compartment compatibility gate, `ai_training_permitted` as a first-class grant — SIG-LIC-001…012.
4. **Publication policy** (§43): the C1–C5 **coordinate sensitivity matrix**, the **five-prong officer-naming test** with two-reviewer concurrence, categorical exclusions, the de-pseudonymisation prohibition, jurisdiction-conditional publication — SIG-PUB-001…017.
5. **Threat model** (§44) as a maintained, versioned artifact where every adversary row maps to a requirement id — SIG-SEC-001…006.
6. **ADR-001…ADR-012** (§15.5) **plus stack ADRs**: uv (lockfile tool), Astro (web), **AWS S3 evidence + CloudFront CDN for bulk exports** (reconciling the §38.5 egress constraint), Dagster (SIG-INGEST-020), and lower-stakes defaults FastAPI / MapLibre / pytest+Hypothesis / GitHub Actions. Each names a revisit trigger.

## Out of scope (do NOT do here)
- Prose governance — takedown/corrections/suppression (§45), governance & Code of Conduct + the anti-misuse statement (§46), contributor safety (§34.3) — **P00.3** owns these.
- Seeding the source registry or recording outreach outcomes — **P00.4**.
- Any connector/schema/evidence-store code that *enforces* these rules at runtime — later phases (this ticket ships the rule + test, not the pipeline that calls it).
