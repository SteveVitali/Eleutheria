## Goal
Expand sources in the **accountability/governance dimension** — more contract/funding/policy/oversight
sources, fusion-center/RTCC governance, under-covered jurisdictions — **not** maximal commodity camera
points; each new source runs through P28.1 resolution so it **deepens** the graph rather than enlarging an
unresolved pile.

## In scope — deliverables
1. Enumerate + add **high-signal, relationship-weighted** sources (accountability/governance first),
   each `ingestion_permitted=false` behind a rights packet; flips are HG-03 (operator).
2. Each yielding source runs through the **P28.1 resolution** pipeline (dedup into resolved entities) and
   the P27.2 rights pipeline (evidenced licence) — breadth that compounds the resolved graph.
3. Honest recorded outcomes per source; cadence rows for yielding sources; ladder re-measured.

## Out of scope

  that don't dedup into the resolved graph (they'd re-create the unresolved-pile problem).
