## Goal

The spine learns the difference between a copy and a coincidence: under **ruleset v3** (L3 §4.6 verbatim), a record may auto-collapse **only** into a copy of one upstream record — **C0** (the same layer ingested twice under one source — the ADR-116 duplicate-target lineage), **C1** (the same value in a declared `id_namespace` of a declared lineage, unique in both captures, within the copy tolerance), **C2** (a one-to-one exact-position match inside a lineage declared with documentary evidence, measured overlap ≥ 0.9, bijective within 5 m, within the M-3 copy tolerance, no attribute conflict — enabled per Q-L3-6 = a). Every collapse is recorded as a **derivation link** (`derived_from` + lineage evidence) and a **shared site id** in a new append-only run — never an entity merge; `merged_into` is never written (ADR-105 §6). Every inferential match — 3g across independent lineages, 1g without a namespace, 4g, 5g, soft conflicts, refused unions, shape alerts — is a **`possible_duplicate` link with basis, distance and reason**, staying review-only, never auto-written (SIG-EVAL-004 stands in full for every inferential tier; the waiver is C0–C2 only, ADR-153). The **GQ-23 census re-verifies every collapse on every run** and a failing lineage demotes automatically; **GQ-25** refuses any collapse that puts two records one origin lists as distinct into one cluster (worst failure is over-counting — the conservative direction); the **device-kind soft conflict** derives from the declared `technology` claim (the description-based half stays `D-P30.2b-2`); hard constraints hold (clusters ≤ 50 m and ≤ 6 members, never incompatible technology — ADR-105 §4). Count-interval computation is emitted for the publish row (326) to render — copies collapsed for the upper bound, every possible duplicate within the declared distance merged for the lower bound (F-520's inflated dossiers get their range, never a silent point count).
